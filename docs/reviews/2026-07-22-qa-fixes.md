## #1 · LNB 로그인/회원가입 버튼 아이콘–텍스트 gap (6→8px)

## #3 · 사이드바 버튼 패턴 공통화 (스타일 drift 방지)

- **지적**: nav/help/profile/login row가 동일 구조(`flex items-center gap p-[12px] rounded-[8px]` + hover)를 각자 하드코딩 복붙 → #2 hover drift의 근본 원인. 공통화 필요(Button variant vs sidebar 전용 컴포넌트).
- **판단 (Option A, 스코프 있는 추출)**: 전면 공통화(로고·접기까지 한 컴포넌트 + variant props)는 `icon|avatar`·`link|button`·`cta`·`active` 조건 prop이 붙어 leaky해짐 → 지양. `components/ui/button.tsx`(shadcn/Base UI, `h-8`·shadcn 토큰)도 사이드바(`p-[12px]`·cosmos 토큰)와 체계가 달라 재사용 부적합. 대신:
  - `SIDEBAR_ROW_BASE` 클래스 상수 신설 — `sidebarRowClass`(nav+help)·프로필 버튼이 공유. padding/radius/hover가 개별 drift 불가.
  - `SidebarNavRow` presentational 컴포넌트 추출 — `아이콘+라벨+툴팁` 행. nav 5종 + 도움말이 사용, 반복 JSX·툴팁 배선 제거.
  - **로그인 버튼은 의도적 예외 유지** — `justify-center`·`gap-[8px]`·`bg-primary`·`text-white`로 base와 근본이 달라 공유 시 override 범벅. filled CTA로 존치.
- **수정**: `Sidebar.tsx` — `LnbTooltip` 아래 모듈 레벨에 `SIDEBAR_ROW_BASE`/`sidebarRowClass`/`sidebarLabelClass`/`SidebarNavRow` 추가, 컴포넌트 내부 `labelClass`/`itemRowClass` 제거, nav map·help·프로필 버튼 배선 교체.
- **검증**: 클래스 문자열 원본과 동일(behavior-preserving), `tsc --noEmit` exit 0, eslint exit 0.

## #4 · fixed 지도 — 채팅 패널 접기 시 지도가 빈 영역을 채우지 못함

- **지적**: fixed 페이지에서 "채팅 패널 접기"(`aria-label="채팅 패널 접기"`, `chatOpen=false`)로 좌측 패널을 접으면, 지도가 넓어진 영역을 채우지 못하고 회색으로 남음.
- **원인**: `useKakaoMap.ts`의 ResizeObserver가 `map.relayout()`을 **`becameVisible`(이전 크기 0→양수, 숨김→표시)일 때만** 호출. 패널 접기/펼치기는 지도 컨테이너 너비가 `left-[384px] ↔ left-0`로 바뀌는 **일반 리사이즈**(두 차원 모두 0 아님)라 relayout이 누락됨. 카카오 지도는 컨테이너 크기 변경 시 `relayout()`을 호출해야 타일을 다시 그린다.
- **수정**: `useKakaoMap.ts` ResizeObserver — 크기가 바뀌면(`sizeChanged`, 양수 유지) 항상 `map.relayout()` 호출. 재센터링/`fitToMarkers`는 기존대로 `becameVisible`(모바일 숨김→표시)에만 실행. `relayout()`은 중심·줌을 보존하므로 패널 토글 시 지도가 튀지 않음. `width/height===0`이면 조기 반환(값만 기록).
- **검증**: `tsc --noEmit` exit 0, eslint exit 0. (브라우저 통합 동작이라 단위테스트 미작성 — 아래 메모 참조.)
