# Recommend V2 — 새로운 추천 파이프라인

> 2026-05-27 lala 지시사항 정리

## Goal

기존 `/recommend` 파이프라인은 유지하되, **새로운 추천 방식의 API**를 추가한다.

**핵심 아이디어:**
- 매체 데이터를 키-밸류(코드 + 키워드)로 구조화
- LLM이 키워드 추출 → DB 필터링 → LLM이 최종 선택
- 프론트에서 기존/신규 탭 비교

## 현재 데이터 구조

### Sheet1: 매체 데이터 (913개)

| 필드 | 예시 | 비고 |
|------|------|------|
| `media_source` | "FIXED" | 매체 유형 |
| `detail.name` | "신사 BK빌딩" | 매체명 |
| `list.advertisement_fee` | 10000000 | 광고비 |
| `thumbnail_url` | "https://..." | 썸네일 |
| `all_image_urls` | "url1 \| url2" | 상세 이미지 |
| `IND (업종 라벨)` | "①IND-05 명품·럭셔리 / ②IND-03 화장품·뷰티" | 라벨 문자열 |
| `PRD (제품 라벨)` | "①PRD-06 가방·잡화 / ..." | 라벨 문자열 |
| `OBJ (목적 라벨)` | "①OBJ-03 프리미엄 브랜딩 / ..." | 라벨 문자열 |
| `TGT (타깃 라벨)` | "①TGT-30 [B] 유동인구 전반 / ..." | 라벨 문자열 |
| `LOC (지역 라벨)` | "①LOC-01 강남역·테헤란로 / ..." | 라벨 문자열 |

### Sheet2: 키-밸류 사전

| 카테고리 | 코드 수 | 예시 |
|----------|--------|------|
| 업종 (IND) | 28개 | IND-01: 금융, 은행, 시중은행, ... |
| 제품 (PRD) | 32개 | PRD-01: 스킨케어, 코스메틱, 뷰티, ... |
| 목적 (OBJ) | 15개 | OBJ-01: 신제품 런칭, 신상품, ... |
| 타깃 (TGT) | 30개 | TGT-01: 10대, 10대 후반, ... |
| 지역 (LOC) | ~50개 | LOC-01: 강남역, 강남대로, 테헤란로, ... |

## Proposed Flow

```
[1] 유저 채팅
      ↓
[2] LLM 키워드 추출 (새 호출)
    - Sheet2 키워드 사전 참조
    - 사용자 언어 → 코드 매핑 (IND-01, LOC-01 등)
      ↓
[3] DB 필터 (AND 필터)
    - 추출된 코드들로 AND 매칭
      ↓
[4] 결과 처리
    ┌─────────────────────────────────────────┐
    │ 매칭 0개:                                │
    │ "조건에 맞는 매체를 찾기 어려워요.        │
    │  [지역/제품/예산] 등을 알려주시면         │
    │  적합한 광고를 찾아드릴게요 😊"          │
    │                                          │
    │ 매칭 1개:                                │
    │ "한 개의 매체를 찾았어요.                │
    │  더 구체적인 조건을 알려주시면            │
    │  더 적합한 것을 찾아드릴게요 😊"          │
    │                                          │
    │ 매칭 2개↑:                              │
    │ → 필터링된 리스트 먼저 노출               │
    │ → "N개 찾았습니다. 더 구체적인 조건을    │
    │   알려주시면 최적의 것을 추천해드릴게요"  │
    └─────────────────────────────────────────┘
```

## 비고

- 기존 `/recommend`는 수정하지 않음
- 슬롯 재사용하지 않음 (별도 LLM 호출)
- 토큰 최적화: 매체 정보는 이름 + 가격 + 지역 + 카테고리만 (설명 미포함)
- 매칭 수 ≥ 2일 때 리스트 먼저 노출 + 채팅 유도
