# V2 챗봇 챗 문구 일람 (기획 전달용)

**작성일**: 2026-06-01
**대상**: 기획자
**목적**: V2 광고 매체 추천 챗봇의 모든 사용자 노출 문구를 한눈에 검토

---

## 응답 유형 (Type)

| Type | 의미 | UI 표현 |
|---|---|---|
| `chat` | 단순 안내 메시지 | 텍스트만 |
| `need_more` | 슬롯 부족 (0~1개) — 추가 조건 요청 | 텍스트 + 매칭된 조건 칩 |
| `list` | 매체 추천 결과 (슬롯 2개 이상) | 텍스트 + 매체 리스트 |
| `confirmation_required` | 슬롯 충돌 → 예/아니오 확인 요청 | 경고 박스 + 변경 내용 + 빠른답 버튼 |

> 슬롯 6축: **업종 / 제품 / 목적 / 타깃 / 지역 / 카테고리** + **예산**(단일값)

## 2. 챗봇 응답 — 일반 발화

### 분기 흐름

```
사용자 발화
  ├─ 직전 턴이 확인 요청(B1)이었는가?
  │   ├─ "예/네/y/ok…"      → B2 (조건 교체 + 결과)
  │   ├─ "아니오/no/취소…"  → B3 (기존 조건 유지)
  │   └─ 그 외               → 새 발화로 간주, 아래로
  ├─ 키워드 추출
  ├─ 기존 슬롯과 충돌?       → B1 (예/아니오 확인)
  ├─ 슬롯 0개                → B4 (조건 더 요청)
  ├─ 슬롯 1개                → B5 (1개 더 요청)
  ├─ 슬롯 2개+ / 결과 0건    → B7 (결과 없음)
  └─ 슬롯 2개+ / 결과 있음   → B6 (매체 리스트)
```

### 문구 표

| ID | Type | 트리거 | 문구 |
|---|---|---|---|
| **B1** | `confirmation_required` | 기존 슬롯에 다른 값 진입 (충돌) | 기존에 설정된 조건과 충돌하는 항목이 있어요. 교체할까요? (예/아니오)<br>　· {카테고리}: {기존값} → {새값} |
| **B2** | `chat` + `list` | 확인 요청에 "예" | (1) 조건을 교체했어요:<br>　· {카테고리}: {기존값} → {새값}<br>(2) 이어서 매체 리스트 출력 |
| **B3** | `chat` | 확인 요청에 "아니오" | 기존 조건을 유지할게요. 추가 조건을 알려주세요 😊 |
| **B4** | `need_more` | 슬롯 0개 | 어떤 광고를 원하시는지 조금 더 구체적으로 알려주세요. 지역, 제품, 카테고리, 타깃 등이 도움이 됩니다 😊 |
| **B5** | `need_more` | 슬롯 1개 | 현재 조건: {요약}<br>조건을 1개 더 알려주시면 적합한 광고를 찾아드릴게요 😊 |
| **B6a** | `list` | 슬롯 2개+ / 결과 > 20 | 조건에 맞는 매체를 {total}개 찾았어요. {N}개만 먼저 보여드릴게요 😊 |
| **B6b** | `list` | 슬롯 2개+ / 결과 ≤ 20 | 조건에 맞는 매체를 {total}개 찾았어요. |
| **B7** | `list` | 슬롯 2개+ / 결과 0건 | 조건에 맞는 매체를 찾지 못했어요. 조건을 조금 다르게 알려주시면 다시 찾아드릴게요 😊 |
| **B8** | `error` | 시스템 예외 | {예외 메시지} |

### "예/아니오" 인식 패턴

| 긍정으로 처리 | 부정으로 처리 |
|---|---|
| yes / y / 네 / 예 / 응 / 그래 / 맞아 / ok / 오케이 / 좋아 / 변경(해) / 바꿔(줘) / 교체 | no / n / 아니(요/다) / 싫어 / 취소 / 안 해 / 그대로 / 유지 |

### 요약 포맷 ({요약})

```
업종: 화장품 / 지역: 강남 / 예산: 5,000만원 이하
```

- 카테고리는 사전 description으로 표시
- 예산만 "**이하**" 접미사 (상한값 의미)

## 3. 챗봇 응답 — 슬롯 X버튼 제거

조건 슬롯을 X 버튼으로 직접 제거할 때.

| ID | Type | 트리거 | 문구 |
|---|---|---|---|
| **R0** | (사용자 가상 메시지) | X 버튼 클릭 | "{카테고리}: {값}" 조건 제거 |
| **R1** | `chat` | 제거 후 슬롯 0개 | 조건이 모두 제거되었어요. 새 조건을 알려주세요 😊 |
| **R2** | `need_more` | 제거 후 슬롯 1개 | 현재 조건: {요약}<br>조건을 1개 더 알려주시면 적합한 광고를 찾아드릴게요 😊 |
| **R3** | `list` | 제거 후 슬롯 2개+ | (B6 / B7과 동일) |
| **R4** | `error` | 잘못된 카테고리 | 잘못된 카테고리: {category} |

## 4. 일관성 점검 포인트 (정리/통일 필요)

| # | 항목 | 사례 |
|---|---|---|
| 1 | 이모지 사용 일관성 | "😊"가 안내성 문구 대부분에 붙는데, B1(확인 요청)·B2(교체 완료)·R4(에러)에는 빠짐 |
| 2 | 결과 0건 멘트 차이 | 일반 발화 B7은 "찾지 **못했어요**" / 호환 엔드포인트는 "찾기 **어려워요**" |
| 3 | 매체 개수 표현 조사 | "{N}개**만** 먼저" / "{N}개**를** 먼저" — 조사 통일 필요 |
| 4 | need_more 0개 vs 1개 시작 어구 | 0개: "어떤 광고를 원하시는지..." / 1개: "현재 조건: ..." — 시작 패턴 통일 가능 |
| 5 | "매체" vs "광고" 혼용 | 본문 "**매체**를 찾았어요" / 안내 "**광고**를 찾아드릴게요" — 도메인 용어 통일 |
| 6 | R0 사용자 가상 메시지 표기 | `"업종: 화장품" 조건 제거` — 큰따옴표 + 콜론, 한국어 문장에 이질감 |
| 7 | B1 메시지 중복 | 본문 "기존에 설정된 조건과 충돌..." + UI 헤더 "⚠️ 조건 변경 확인 필요" + 하단 바 "조건을 교체할까요?" → 같은 의미 3번 |
| 8 | 첫 진입 가이드 vs need_more 6축 vs 4축 | F2는 6축 모두 안내(지역/예산/제품/업종/목적/타깃) / B4는 4개만(지역/제품/카테고리/타깃) |
| 9 | 예산만 "이하" 접미사 | 다른 슬롯은 단순 표기, 예산만 "5,000만원 이하" — 의도된 표기인지 확인 |

## 5. 정의가 필요한 누락 케이스

| # | 케이스 | 현재 동작 | 검토 사항 |
|---|---|---|---|
| 1 | 확인 요청 상태에서 예/아니오가 아닌 새 발화 입력 | 안내 없이 새 응답으로 진행 | "이전 확인을 취소하고 새 조건을 적용했어요" 안내 필요? |
| 2 | 예산만 단독 입력 (예: "5천만원만") | need_more 1개로 처리 | "예산만으로는 검색이 어려워요" 별도 분기 필요? |
| 3 | 슬롯 다수인데 결과 0건 | B7 일반 안내 | 어떤 조건을 빼면 결과가 있는지 힌트 제공 가능 |
| 4 | 이미 적용된 조건을 다시 입력 (예: 이미 "강남"인데 또 "강남") | 변화 없이 list/need_more 반환 | "이미 적용된 조건이에요" 안내 필요? |
| 5 | 확인 요청 없을 때 사용자가 "예/아니오"만 입력 | 일반 발화 → 추출 없음 → B4 | 자연스러운 흐름이긴 함 |
| 6 | 세션 만료/삭제 후 메시지 전송 | 새 세션처럼 빈 상태로 동작 | "세션이 만료됐어요" 안내 필요? |
| 7 | 네트워크 끊김 (스트림 중단) | "오류: ..." 토스트 + 에러 버블 | 재시도 버튼 / 자동 재연결 |
| 8 | AI 추출 타임아웃/실패 | 에러 메시지(영문 시스템 메시지 가능) 그대로 노출 | 사용자 친화적 메시지로 감싸야 함 |
| 9 | 매체는 있는데 모두 가격 미기재 | 정렬은 0으로 처리, 리스트는 표시 | 가격 미기재 다수 시 안내 필요? |
| 10 | 20개 초과 결과의 "더보기" | 현재 없음, "20개만 먼저 보여드릴게요"만 안내 | 페이지네이션 / 더보기 정책 정의 필요 |

## 6. 의사결정이 필요한 항목 요약

기획에서 결정해주실 항목:

- [ ] 이모지(😊) 사용 정책 — 어떤 문구에 붙일지 일관 기준
- [ ] "매체" / "광고" 용어 통일 (도메인 용어 결정)
- [ ] need_more / 결과 0건 / 첫 가이드의 안내 슬롯 축 (4축 vs 6축)
- [ ] B1 확인 요청 메시지 중복 정리 (어떤 영역에 메시지를 둘지)
- [ ] 누락 케이스 1~10 중 우선 처리 항목
- [ ] 예산 슬롯의 "이하" 접미사 유지 여부
