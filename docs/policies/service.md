## 1. 목적
ADMIX 서비스와 회사를 소개하는 **정적 랜딩성 화면**이다. 서비스 특징(지도 탐색 / AI 추천 / 제안서·계약)과 타사 대비 차별점을 보여주고, 하단 CTA로 매체 탐색(`/fixed`)으로 유도한다.

- 핵심 사용자: 서비스를 처음 접하거나 소개가 필요한 방문자
- 성공 기준: ❓ (예: CTA "매체 둘러보기" 클릭률 — 미정)

## 2. 권한
접근 제한 없음 — 전체 사용자(비회원 포함). 화면 자체에 권한/한도 개념 없음.

## 3. UI 블록 (위 → 아래)

화면은 세로 1열 스크롤 구성이며, 단일 컨테이너(최대 폭 1016px) 안에 5개 섹션이 순서대로 쌓인다. 마지막 CTA 링크 외에는 **모두 정적 표시 요소**다.

### 3.1 페이지 제목 + 히어로 배너
- **기능**: 화면 상단 타이틀("서비스 소개" + "회사 및 서비스 소개를 확인하세요")과 브랜드 히어로 배너.
- **규칙**:
  - 히어로 배너: 배경 이미지 위 ADMIX 워드마크 로고 + 카피("광고 캠페인을 AI와 대화로 / 탐색부터 계약까지 전 과정을 하나의 대화로 완성합니다.").
  - 링크·상호작용 없음(정적 표시).

### 3.2 소개 섹션 ("스타트업부터 중견기업까지")
- **기능**: 헤드라인 + 대표 소개 이미지.
- **규칙**: 텍스트 + 이미지(`/service/intro.png`) 정적 표시. 상호작용 없음.

### 3.3 비교 섹션 (타사 vs ADMIX)
- **기능**: 타사 서비스와 ADMIX를 항목별로 비교하는 2열 표.
- **규칙**:
  - 좌열 "타사 서비스", 우열 "ADMIX", 각 열 상단에 대표 이미지/로고.
  - 각 열은 고정된 **6개 항목**을 체크 아이콘과 함께 나열(코드 상수 `OTHER_ROWS`/`ADMIX_ROWS`).
    - 타사: 대행사 선정에 수주 소요 / 제안서 작성에 수일~수주 / 전문 지식 없으면 불가능 / 영업 담당자에게 강한 의존성 / 별도 제안서 제작 필요 / 여러 창구 문의 및 방문.
    - ADMIX: AI와 대화로 즉시 시작 / 단시간에 플래닝 완성 / 누구든 전문가급 전략 수립 / 데이터 기반 실제 매체 추천 / 자동 즉시 생성·다운로드 / 문의·계약까지 원스톱.
  - 항목은 하드코딩 정적 데이터. 상호작용 없음.

### 3.4 기능 카드 섹션 ("AI Planning")
- **기능**: 서비스 핵심 기능 3종을 카드로 소개.
- **규칙**:
  - 고정 **3개 카드**(코드 상수 `CARDS`): ① 지도 위에서 한눈에 보는 광고 매체 ② 매체 탐색 및 AI 추천 시스템 ③ 제안서 즉시 발송 그리고 집행.
  - 각 카드: 뱃지(사용 상황 문구) + 제목 + 설명 + 이미지. 상호작용·링크 없음(정적 표시).

### 3.5 하단 CTA 배너
- **기능**: 매체 탐색으로 이동시키는 유일한 행동 유도 요소.
- **규칙**:
  - 카피("AI와의 대화 한 번으로 첫 캠페인이 완성됩니다. / 복잡한 기획 없이 지금 바로 시작해 보세요.").
  - **"매체 둘러보기" 링크 클릭 시 `/fixed`(고정매체)로 이동.** (Next `<Link href="/fixed">`)
  - 비회원 포함 전체 이동 가능(별도 로그인 게이트 없음).
