# 도움말 화면 정책서 (UI중심)

> **이 문서는 "이 화면이 어떤 규칙으로 동작하는가"를 정의합니다.**
> 화면을 위→아래 **UI 블록 순서**로 읽습니다. 각 블록은 **"무엇 + 동작 규칙"**만 적고, 디자인(색·여백·컴포넌트 모양)은 Figma에 둡니다. 미정은 줄 안에 `❓`로 표시하고 맨 아래 "미정" 섹션에 한 번 더 모읍니다.

| | |
|---|---|

| **진입** | LNB 사이드바 "도움말" 아이콘 클릭 · URL 쿼리 `?tab=terms\|privacy\|location`로 특정 탭 직접 진입 |
| **Figma** | ❓(미확인) |

## 1. 목적
회사(ADMIXAI)의 **이용약관 · 개인정보 처리방침 · 위치기반 약관** 세 가지 법적 문서를 탭으로 전환하며 열람하는 정적 문서 뷰어 화면이다. 입력·제출 없이 읽기 전용으로 동작한다.

- 핵심 사용자: 서비스 약관을 확인하려는 모든 방문자(비회원 포함)
- 성공 기준: 해당 없음(정적 열람 화면)

## 2. 권한
접근 제한 없음 — **전체 사용자**(비회원 포함)가 열람 가능. 로그인·권한 분기 없음. 한도 없음.

---

## 3. UI 블록 (위 → 아래)

화면은 상단 스크롤 영역 안에 **① 페이지 타이틀 → ② 탭 바 → ③ 본문 → ④ Footer** 순으로 세로 배치된다.

### 3.0 페이지 타이틀
- **기능**: 화면 제목 "도움말" 고정 노출.
- **규칙**: 항상 "도움말" 텍스트만 표시. 탭이 바뀌어도 변하지 않는다.

### 3.1 탭 바 (이용약관 / 개인정보 처리방침 / 위치기반 약관)
- **기능**: 3개 문서 중 하나를 선택해 본문을 전환하는 탭.
- **규칙**:
  - 탭 3개: `terms`(이용약관) · `privacy`(개인정보 처리방침) · `location`(위치기반 약관). 순서 고정.
  - **초기 탭 결정**: 진입 URL 쿼리 `?tab=` 값이 3개 키 중 하나와 일치하면 그 탭으로 시작, 아니면(값 없음/오타 포함) **`terms`(이용약관)**로 시작.
  - 탭 클릭 시 해당 문서로 본문 즉시 교체(클라이언트 상태 전환, 페이지 재요청·URL 변경 없음).
  - 선택된 탭은 강조 표시, 나머지는 비활성 표시(동작상 구분만, 색상은 Figma).
- `❓` URL 쿼리(`?tab=`)로 딥링크 진입은 가능하나, 탭을 눌러도 URL은 갱신되지 않음 — 딥링크/공유 URL 갱신이 필요한지 미정.

### 3.2 본문 (약관 텍스트)
- **기능**: 선택된 탭의 문서 전문(全文)을 표시.
- **규칙**:
  - 문서 내용은 프런트 상수(`content.ts`)에 하드코딩된 정적 텍스트. 서버/API 조회 없음.
  - 줄바꿈·들여쓰기를 원문 그대로 보존해 렌더(`whitespace-pre-wrap`). 마크다운/HTML 파싱 없이 순수 텍스트.
  - 선택 탭에 따라 문자열만 교체되며, 그 외 동작 없음(링크·버튼 등 인터랙션 요소 없음).
- `❓` 약관 내 이메일(contact@admixai.co.kr)·외부 URL(kopico.go.kr 등)의 클릭 링크화 여부 — 현재는 텍스트로만 노출.

### 3.3 Footer
- **기능**: 전역 공통 Footer 컴포넌트 노출.
- **규칙**: 본문 하단에 항상 표시. 도움말 화면 전용 로직 없음(전역 Footer 정책 별도).

## 4. 화면 상태
정적 화면이므로 로딩/에러/빈 상태가 없다.

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 기본 | 진입(쿼리 없음/무효) | `terms` 탭 + 이용약관 본문 |
| 딥링크 진입 | `?tab=privacy` 또는 `?tab=location` | 해당 탭 + 해당 본문 |
| 로딩 / 결과 없음 / 에러 | 해당 없음 | 정적 상수 렌더로 미발생 |

---

## 5. 데이터 & 연동
API·외부 연동 없음. 약관 3종 텍스트는 프런트 상수(`app/(client)/(main)/help/content.ts`)에 정적으로 포함.

| 항목 | 출처 / 연동 | 트리거 · 비고 |
|---|---|---|
| 이용약관·개인정보처리방침·위치기반약관 전문 | 프런트 상수(`content.ts`) | 빌드 시 포함, 런타임 조회 없음 |
