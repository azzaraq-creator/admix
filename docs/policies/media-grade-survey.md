# 매체 등급 설문 질문 목록

어드민 > 광고 매체 상세 > 등급·추천의 "등급 설문"에서 묻는 질문입니다. 매체 종류에 따라 질문 묶음이 달라집니다.
설문에 답하면 아래 "점수" 기준으로 **품질 점수가 자동으로 매겨지고, 품질 점수에 따라 최종 등급이 자동으로 정해집니다.** 최종 등급은 관리자가 직접 고를 수도 있습니다.

- 질문·답별 점수·계산 코드: `frontend/app/admin/(main)/media/_components/gradeSurveyQuestions.ts` (질문 옆 `points`가 점수)
- 저장 위치: `media.grade_survey` — `{질문 ID: 답 값}` JSON. 메모는 `note`.
- 질문·답 문구는 고쳐도 되지만, **ID·값은 저장값이라 답을 모으기 시작하면 바꾸지 않습니다.**
- 크기·유동인구는 데이터로 자동 계산할 예정이라 설문에 넣지 않았습니다.

## 유동인구 단계 (자동 — 묻지 않음)

설문 맨 위에 보이고, 옆 "?"를 누르면 기준표가 뜹니다. 백엔드 `media_service.population_tier`가 저장된 매체 값으로 계산합니다.

- 대상: **서울 고정 매체, 야립빌보드 제외.** 이동 매체·서울 밖은 "해당 없음"입니다.
- **야립빌보드는 이 자리에 "교통량 단계"가 대신 보입니다.** 차량 교통량 데이터를 아직 가져오지 않아 지금은 늘 "데이터 없음"이고, "?"에는 교통량으로 매기는 이유와 그동안 '차량 통행량' 질문으로 대신 매긴다는 안내가 뜹니다. 교통량 데이터를 붙이면 단계 기준표를 넣습니다.
- 값: 매체 정보 팝업의 월평균 유동인구와 같습니다 — 직접 입력한 값, 없으면 서울시 상권 값(매체 반경 500m 안에서 가장 붐비는 상권의 최신 분기 ÷ 3).
- 기준(`POPULATION_TIERS`): 2026-10-15 운영 서울 고정 매체 536개 분포에서 매체 수가 고르게 나뉘게 정했습니다.

| 단계 | 월평균 유동인구 | 당시 매체 수 |
|---|---|---|
| 5 | 200만 명 이상 | 73 (14%) |
| 4 | 100만 ~ 200만 | 87 (16%) |
| 3 | 70만 ~ 100만 | 114 (21%) |
| 2 | 40만 ~ 70만 | 164 (31%) |
| 1 | 40만 미만 | 98 (18%) |

## 어떤 질문 묶음이 나오나

| 매체 | 질문 묶음 |
|---|---|
| 고정 · 외부형 · DOOH | 실외 매체 + 디지털 화면 |
| 고정 · 외부형 · OOH | 실외 매체 + 일반(인쇄) 매체 — 야간 조명 |
| 고정 · 공간형 · DOOH | 실내 매체 + 디지털 화면 |
| 고정 · 공간형 · OOH | 실내 매체 + 일반(인쇄) 매체 — 조명 |
| 이동 · DOOH | 이동 매체 + 디지털 화면 |
| 이동 · OOH | 이동 매체 + 일반(인쇄) 매체 — 광고 면 크기 |
| 고정 · 야립빌보드(소분류) | 차량 통행량 + 야립 광고 + 일반(인쇄) 매체 — 야간 조명 (DOOH면 디지털 화면) — 설치 장소와 상관없음 |
| 고정인데 설치 장소를 안 고름 | 질문 없음 — "설치 장소를 먼저 고르라"는 안내 |

야립이 아닌 고정 매체는 위 묶음 앞에 하나가 더 붙을 수 있습니다.

| 고정 매체 | 맨 앞에 붙는 묶음 |
|---|---|
| 유동인구 단계가 없음 — 서울 밖·인구 데이터 없음 | 유동인구 (데이터 대신) |
| 유동인구 단계가 있음 | 없음 — 자동 단계를 씀 |

유동인구 단계가 있는지는 **저장된 값** 기준입니다. 새 매체는 저장하기 전까지 "주변 유동인구"가 보이고, 저장해서 단계가 매겨지면 사라집니다.

모든 묶음 아래에 자유 메모 칸(`note`)이 있습니다.

| 3 | 가시거리 (`view_distance`) | 광고 내용을 알아볼 수 있는 가장 먼 거리 | 200m 이상 (`200_plus`) · 100 ~ 200m (`100_200`) · 50 ~ 100m (`50_100`) · 50m 미만 (`under_50`) |

## 야립 광고 (`roadside`) — 야립빌보드만, 실외 매체 질문 대신

운전자가 빠르게 지나가며 멀리서 보는 매체라 실외 매체 질문(교차로·신호 대기·설치 높이·도로 폭)이 맞지 않아 따로 묻습니다.

| # | 질문 (ID) | 설명 | 답 (값) |
|---|---|---|---|
| 1 | 가시거리 (`view_distance`) | 차에서 광고 내용을 알아볼 수 있는 가장 먼 거리 | 500m 이상 (`500_plus`) · 300 ~ 500m (`300_500`) · 150 ~ 300m (`150_300`) · 150m 미만 (`under_150`) |
| 2 | 도로 모양 (`road_shape`) | 다가오는 차에서 매체가 어떻게 보이는지 | 직선 구간 정면 (`straight_front`) · 곡선 바깥쪽(정면으로 들어옴) (`curve_outer`) · 옆으로 지나치며 봄 (`side`) |
| 3 | 차량 속도 (`vehicle_speed`) | | 자주 막히거나 서행(톨게이트·JC 근처 등) (`slow`) · 보통 (`normal`) · 늘 빠름 (`fast`) |
| 4 | 가림 (`obstruction`) | 방음벽·나무·다른 구조물에 가려지는 정도 | 없음 (`none`) · 일부 가림 (`partial`) · 많이 가림 (`heavy`) |
| 5 | 보이는 방향 (`view_directions`) | | 양방향 모두 (`both`) · 한 방향만 (`one`) |
| 6 | 도로와의 거리 (`road_distance`) | | 50m 이내 (`under_50`) · 50 ~ 150m (`50_150`) · 150m 이상 (`150_plus`) |
| 7 | 주변 다른 야립 (`competition`) | 한눈에 같이 보이는 다른 야립 수 | 단독 (`alone`) · 2 ~ 3개 (`few`) · 4개 이상 (`many`) |

가시거리는 실외 매체와 같은 ID지만 선택지가 다릅니다 — 매체 종류를 바꾸면 맞지 않는 답은 저장할 때 빠집니다.

## 점수

> 실제 답을 모으기 전에 임의로 정한 값입니다. 답이 쌓이면 분포를 보고 조정합니다.

### 화면에서

등급·추천 탭 맨 위 순서: **품질 점수 → 최종 등급 → 등급 설문**. ("타깃(유동인구) 요약"은 이 탭에서 뺐습니다 — 믹시용 값이라 저장할 때 자동으로 계속 다시 써집니다.)

- **품질 점수 — 보기 전용.** 설문 답을 고르는 대로 바로 다시 계산해 보여 주고, 저장할 때 그 값을 저장합니다.
  - 아래 칩: "설문 답으로 계산했어요" / "임시 · 11문항 중 6개 답함" / 설문 전이면 "원천 데이터 값이에요…".
- **최종 등급 — 자동 또는 직접.** 선택 칸 맨 위가 "자동 (B)"이고, S ~ D를 고르면 직접 지정입니다.
  - 자동: 저장할 때 품질 점수의 등급을 넣습니다(`final_grade_manual = false`).
  - 직접: 고른 등급을 넣고 점수가 바뀌어도 그대로 둡니다(`final_grade_manual = true`). 다시 "자동"을 고르면 점수 등급으로 돌아갑니다.
- **설문 전(질문의 절반 미만만 답함)에는 원천 데이터의 품질 점수·최종 등급을 그대로 둡니다.** 운영 913개 매체는 모두 원천 값(S 86 · A 229 · B 371 · C 137 · D 90, 2026-10-15)이 있고, 사이트·추천 어디에도 쓰이지 않습니다.
- 점수를 매기면 "등급 근거"(`grade_evidence`, 사용하지 않는 값 구역)에 "등급 설문 89점 · S | 유동인구 단계 5단계 30/30 · 가시거리 200m 이상 12/12 …"처럼 남깁니다.
- 유동인구 단계는 **저장된** 값으로 계산합니다. 서울시 새 분기가 들어와 단계가 바뀌어도 품질 점수는 그 매체를 다시 저장할 때 바뀝니다.

### 계산 방식

- **어떤 매체든 만점이 100점**이 되게 짰습니다.
  - 고정 매체: 유동인구 30 (자동 단계, 없으면 "주변 유동인구"·야립은 "차량 통행량" 질문) + 설문 65 + 추가 5 (디지털 화면 또는 일반 매체 질문)
  - 이동 매체: 설문 95 + 추가 5
- 점수 = 얻은 점수 합. 다만 **답하지 않은 질문이 있으면** 답한 질문의 만점 합으로 나눠 100점으로 환산하고, 점수 옆에 **"임시"**를 붙입니다. 질문의 절반 미만만 답했으면 점수를 보여 주지 않습니다.

### 예시

서울 외부형 DOOH(강남역 전광판) — 유동인구 5단계(30) + 교차로 모서리(12) + 8차로 이상(8) + 가시거리 200m 이상(12) + 가림 일부(5) + 정면(8) + 건물 중간(5) + 신호 대기 예(5) + 주변 광고 4개 이상(1) + 선명함(3) + 소리 불가(0)
= 89 / 100 → **89점 · S**

서울 공간형 OOH(지하철역 액자) — 유동인구 2단계(12) + 주 동선(14) + 지나감(4) + 눈높이(10) + 10 ~ 20m(5) + 가림 없음(8) + 4개 이상(1) + 조명 있음(5)

경부고속도로 야립(OOH) — 차량 통행량 매우 많음(30) + 300 ~ 500m(10) + 직선 구간 정면(10) + 보통(6) + 가림 없음(10) + 양방향 모두(8) + 50m 이내(8) + 2 ~ 3개(3) + 야간 조명 있음(5)
