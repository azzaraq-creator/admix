## 1. 목적
관리자가 광고 매체(media)를 **목록으로 조회·검색**하고, **등록/수정/삭제** 및 **사진 업로드**를 하는 화면이다. 등록/수정 폼은 `media` 테이블의 전 컬럼을 다룬다. 공개 클라이언트용 매체 조회(`/media/*`)와 분리된 관리자 전용 CRUD다.

- 핵심 사용자: `media` 권한을 가진 관리자
- 성공 기준: ❓ (미정)

## 2. 권한

접근·조작 모두 **`media` 권한**이 필요하다. 마스터 계정은 권한 설정과 무관하게 전체 허용. 상세 정책은 [관리자 인증·권한 정책](admin-auth-permissions.md) §3 참조.

| 사용자 | 접근 | 비고 |
|---|---|---|
| 마스터 관리자 | 목록·상세·등록·수정·삭제·이미지 전부 | 전체 허용 |
| `media` 권한 보유 관리자 | 목록·상세·등록·수정·삭제·이미지 전부 | 라우터 `/admin/media` = `require_permission("media")` |
| `media` 권한 없는 관리자 | 불가 | 사이드바 메뉴 미노출(UX), API 직접 호출 시 403 |

- 백엔드 라우터(`routers/admin_media.py`)의 목록·상세·생성·수정·삭제·이미지 추가/삭제 **모든 엔드포인트**가 `require_permission("media")` 가드를 건다.
- 프론트 axios 인터셉터가 `/admin/*` 요청에 `admin_token`을 자동 첨부한다.

## 3. UI

### 3.0 목록 화면 (`/admin/media`)

#### 3.0.1 페이지 헤더
- **기능**: 화면 제목 "광고 매체 관리".
- **규칙**: 정적 텍스트.

#### 3.0.2 상단 우측 액션 버튼 (3개)
- **기능**: 목록 상단 우측에 "엑셀 다운로드", "엑셀 일괄 등록", "매체 추가" 버튼.
- **규칙**:
  - **매체 추가**: 클릭 시 `/admin/media/new`(등록 화면)로 이동.
  - **엑셀 다운로드**: 버튼만 존재, 현재 `onClick` 미연결(동작 없음) → 사양 `❓`.
  - **엑셀 일괄 등록**: 버튼만 존재, 현재 `onClick` 미연결(동작 없음) → 사양 `❓`.

#### 3.0.3 검색 필터 바 (CommonTable 내장)
- **기능**: 목록을 필터링하는 검색 영역. 옵션 3종.
- **규칙**:
  - **기간(period)** — dateRange 타입. UI에는 노출되나 **목록 필터 로직에 반영되지 않음**(현재 `keyword`/`type`만 필터). → 미반영 `❓`.
  - **유형(type)** — select. 옵션 `고정` / `이동`. 선택 시 `mediaType`이 일치하는 행만 노출.
  - **키워드(keyword)** — text. placeholder "검색조건을 입력해주세요". 입력값(소문자, trim)이 **매체명(`name`)에 부분일치**하는 행만 노출.
  - 필터는 **클라이언트 측 필터링**이다(전체 목록을 받아 `useMemo`로 걸러냄, 서버 재요청 없음).

#### 3.0.4 매체 목록 표 (CommonTable)
- **기능**: 매체 행 목록. 행 클릭 시 상세로 이동.
- **규칙**:
  - **컬럼**(순서): No(`media_id`) · 매체 유형(고정/이동) · 매체명 · 지역 · 카테고리 · 상품 표시 · 광고비 · 판매유형 · 업데이트 · 등록일.
  - **행 클릭**: 해당 매체의 `/admin/media/{no}`(상세/수정)로 이동.
  - **정렬**: 서버가 `media_id` 오름차순으로 반환.
  - **매체명**: `name` + `second_name`을 공백으로 합쳐 표시(둘 다 없으면 `-`).
  - **지역**: `loc_label`, 없으면 `-`(회색). 최대 180px 말줄임 표시.
  - **카테고리**: `category_small`, 없으면 `-`.
  - **상품 표시**: 대표 플랜(plan_no=1)의 `product_display_name`(없으면 `product_name`), 없으면 `-`.
  - **광고비**: `min_advertisement_fee_krw`를 천단위 콤마, 없으면 `-`.
  - **판매유형**: `sales_type` 코드 매핑(`SINGLE`→단품, `GROUP`→묶음), 없으면 `-`.
  - **업데이트/등록일**: `source_updated_at` / `source_created_at`의 날짜(YYYY-MM-DD), 없으면 `-`.
  - **페이지네이션**: 10개씩 보기(page size select 사용). 총건수는 필터 후 건수.

### 3.1 등록/수정 화면 (`/admin/media/new`, `/admin/media/[id]`)

목록·등록·수정이 동일 폼 컴포넌트(`MediaFormView`)를 공유한다. `mode`가 `create`/`edit`로 갈린다. React Hook Form 사용.

#### 3.1.0 화면 제목
- **기능**: 모드별 제목.
- **규칙**: 등록 = "광고 매체 등록", 수정 = "광고 매체 상세".
- 수정 모드에서 상세 데이터 로딩 중이면 "불러오는 중..." 표시 후 폼 렌더.

#### 3.1.1 매체 사진 섹션 (MediaPhotoSection)
- **기능**: 매체 이미지 업로드/삭제. 폼 최상단.
- **규칙**:
  - 헤더에 현재 개수 표시 "매체 사진 {count}/{50}". **최대 50장**.
  - **업로드 박스** 클릭 → 파일 선택(`accept="image/*"`, **다중 선택 가능**).
  - **수정 모드**: 파일 선택 즉시 서버 업로드(`POST /admin/media/{id}/images`). 성공 시 상세 캐시 무효화로 썸네일 스트립 갱신.
  - **등록 모드**: 매체 ID가 아직 없으므로 즉시 업로드하지 않고 **로컬 대기 파일**로 보관. "저장 시 함께 등록됩니다." 안내 노출. 대기 파일은 `URL.createObjectURL`로 미리보기.
  - **썸네일 삭제(X)**: 수정 모드는 `DELETE /admin/media/{id}/images/{imageId}`, 등록 모드는 대기 목록에서 제거.
  - 최대 개수 도달 시 업로드 박스 비활성화.
  - **이미지 형식 제약(백엔드)**: `.jpg/.jpeg/.png/.webp/.gif`만 허용, **개당 최대 10MB**. 위반 시 400.
  - **대표(썸네일) 규칙(백엔드)**: 매체의 **첫 이미지**가 `is_thumbnail=true`. 대표 이미지를 삭제하면 남은 이미지 중 `sort_order` 최소 항목이 자동 대표가 된다. (이 `is_thumbnail`은 `thumbnail_url` 텍스트 컬럼과 별개로 관리 — 업로드가 `thumbnail_url`을 건드리지 않음.)

#### 3.1.2 입력 필드 그리드 (2열)
- **기능**: `media` 테이블 전 컬럼 입력. 2열 그리드로 나열.
- **규칙**:
  - **매체 ID(`media_id`)**: 그리드 첫 필드.
    - 등록 모드: **필수(별표 `*`)**. 비면 "매체 ID는 필수입니다." 검증 에러. 서버에서도 공백이면 400, 중복이면 409.
    - 수정 모드: **읽기전용(disabled)**, 별표 없음.
  - 나머지 필드는 `mediaFields.ts`의 `MEDIA_FIELDS` 순서대로 렌더. **`media_id` 외에는 프론트 필수값 없음**(전부 선택).
  - **필드 타입별 컨트롤**:
    - `text`/`number`: input(number는 `type=number`).
    - `textarea`/`json`: textarea(2열 전체 폭 차지, `col-span-2`). json은 placeholder "JSON 형식".
    - `boolean`: select(미설정 / 예 / 아니오).
  - **전송 시 값 변환**: 빈 문자열 → `null`. number → `Number()`. boolean → true/false 또는 null. json → `JSON.parse`(파싱 실패 시 해당 필드에 "JSON 형식이 올바르지 않습니다." 에러 표시하고 저장 중단).
  - 필드 목록(라벨 예): 매체명·보조명·건물명·매체 출처·판매 유형·OOH 유형·노출 유형·디바이스 유형·매체 형태·카테고리(대/소)·좌표(위/경도)·최소/최대 광고비·최소/최대 제작비·리드타임·수량·품질/등급 관련·로드뷰·각종 JSON(`markers_vo`, `map_bounds_vo` 등)·원본 생성/수정일시 등 media 전 컬럼.
  - 저장 대상에서 제외되는 자동 컬럼: `created_at`, `updated_at`(백엔드에서 무시). 수정 시 `media_id`도 변경 불가.

#### 3.1.3 하단 액션 버튼
- **기능**: 목록 이동 / 삭제 / 저장.
- **규칙**:
  - **목록**(ListButton, 좌측): `/admin/media`로 이동.
  - **삭제**(수정 모드만): 확인 모달("매체를 삭제하시겠습니까?" / "삭제된 매체는 복구할 수 없습니다." / 확인="삭제"). 승인 시 `DELETE /admin/media/{id}` → 목록 이동. 실패 시 실패 알럿.
  - **저장**:
    - 수정: `PATCH /admin/media/{id}` → 성공 시 목록 이동. 실패 시 "저장 실패" 알럿(서버 에러 메시지).
    - 등록: `POST /admin/media` 로 매체 생성 → 이어서 **대기 이미지들을 순차 업로드** → 목록 이동. 매체 생성 실패 시 "저장 실패" 알럿. 매체는 생성됐으나 이미지 일부 업로드 실패 시 "이미지 업로드 실패"(매체는 저장됨, 수정 화면에서 재시도 안내) 알럿 후 목록 이동.
    - 저장/업로드 진행 중(`isPending`) 저장 버튼 비활성화.

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 목록 로딩 | 목록 조회 중 | CommonTable 기본 처리(별도 스켈레톤 사양 `❓`) |
| 목록 성공 | 데이터 있음 | 표 + 페이지네이션 |
| 결과 없음 | 검색/필터 0건 | 필터 후 빈 표(빈상태 문구 `❓`) |
| 상세 로딩(수정) | 상세 조회 중 | "불러오는 중..." 텍스트 |
| 저장/삭제 실패 | API 에러 | 알럿 모달(서버 에러 메시지) |
| 매체 없음(상세) | 존재하지 않는 id | 백엔드 404 "매체를 찾을 수 없습니다." (프론트 표현 `❓`) |

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 · 비고 |
|---|---|---|
| 매체 목록 | `GET /admin/media` | 목록 진입 시. media + 대표 플랜(plan_no=1) 평면 매핑 |
| 매체 상세(전 컬럼) | `GET /admin/media/{id}` | 수정 진입 시 |
| 매체 생성 | `POST /admin/media` | 등록 저장 |
| 매체 수정 | `PATCH /admin/media/{id}` | 수정 저장 |
| 매체 삭제 | `DELETE /admin/media/{id}` | 삭제 확인 후 |
| 이미지 업로드 | `POST /admin/media/{id}/images` (multipart `file`) | 수정=즉시 / 등록=저장 후 |
| 이미지 삭제 | `DELETE /admin/media/{id}/images/{imageId}` | 썸네일 X 클릭 |
| 업로드 저장 경로 | 서버 `upload_dir/media/{media_id}/{uuid}.ext`, URL `/uploads/media/...` | 파일시스템 저장 |
