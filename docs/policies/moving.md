# 이동매체 화면 정책서 (UI중심)

> **이 문서는 "이 화면이 어떤 규칙으로 동작하는가"를 정의합니다.**
> 화면을 위→아래 **UI 블록 순서**로 읽습니다. 각 블록은 **"무엇 + 동작 규칙"**만 적고, 디자인(색·여백·컴포넌트 모양)은 Figma에 둡니다. 미정은 줄 안에 `❓`로 표시하고 맨 아래 "미정" 섹션에 한 번 더 모읍니다.

## 1. 목적
이동매체(버스·택시 등 `media_source = MOVING`) 목록을 위치 검색·필터로 좁혀 카드로 보고, 카드를 골라 상세 정보를 확인하는 탐색 화면이다. 고정매체(`/fixed`)와 달리 **지도가 없고**, 좌측 목록 + 우측 상세의 2분할 구조다.

- 핵심 사용자: 옥외광고 이동매체를 찾는 광고주/마케터
- 성공 기준: ❓

## 2. 권한
접근 제한 코드는 없음 — 라우트(`/media/moving`, `/media/moving/filter-options`, `/media/{id}`)는 인증 의존성 없이 공개다. 따라서 **전체 사용자(비회원 포함)** 가 목록·필터·상세를 조회할 수 있다. 별도 사용량 한도 없음.

## 3. UI 블록 (위 → 아래 / 좌 → 우)

화면은 좌측이 **① 위치 검색 → ② 필터바 → ③ 매체 카드 목록** 세로 구성이고, 우측이 **④ 매체 상세**다. `sm`(640px) 미만 모바일에서는 좌·우가 한 화면을 공유해 목록/상세가 전환되며, `sm` 이상에서는 좌우가 나란히 보인다.

### 3.1 위치 검색 입력
- **기능**: 지역명·키워드 검색 입력(placeholder "지역명 또는 키워드 검색"). 고정매체와 동일한 `LocationSearchInput` 컴포넌트 재사용.
- **규칙**:
  - 입력값은 `location` 로컬 state에만 저장된다.
  - **현재 코드상 이 입력은 목록 조회에 연결돼 있지 않다** — `onSubmit` 핸들러 없이 submit 시 아무 API도 호출하지 않고, 목록은 필터(칩)로만 갱신된다.
- `❓` 위치 검색이 실제로 무엇을 필터/조회해야 하는지(지오코딩 → bbox? 이름 검색?) 미정.

### 3.2 필터바 (MediaSearchFilter)
- **기능**: 매체 목록을 좁히는 필터. 고정매체와 **동일 컴포넌트** 공유.
- **규칙**:
  - **접힘 상태**: `초기화` 버튼 + 6개 필터 칩(`카테고리`, `가격 범위`, `매체 판매 유형`, `매체 타입`, `설치 장소`, `매체 형태`)이 가로로 나열. 스크롤바를 숨긴 채 **그랩 드래그**(포인터 이동 5px 초과 시 드래그로 판정)로 가로 스크롤. 우측 chevron 버튼으로 펼침.
  - **펼침 상태**: 6개 필터를 2열 그리드로 표시. 상단 탭에서 하나를 선택하면 하단에 해당 옵션이 나온다. 하단에 `초기화` + 접기(chevron) 버튼.
  - **칩 선택(다중)**: `카테고리·매체 판매 유형·매체 타입·설치 장소·매체 형태`는 토글식 다중 선택. 선택 수가 1개 이상이면 칩에 카운트 배지 + 활성 색으로 표시.
  - **가격 범위**: 별도 슬라이더(`PriceRangeFilter`). 최저~최대 전체 범위가 아닐 때(min을 올리거나 max를 내림)만 활성으로 간주. 옵션 응답에 가격이 없으면 "가격 정보를 불러오는 중..." 표시.
  - **초기화**: 모든 필터를 빈 상태(`EMPTY_MEDIA_FILTER`)로 되돌림.
  - **필터 옵션 출처**: `GET /media/moving/filter-options` — MOVING 매체 기준 각 컬럼의 distinct 값. 옵션이 비면 "옵션이 없습니다." 표시.
  - **필터 → 목록 반영**: 필터 변경 시 선택 값이 쿼리 파라미터로 `GET /media/moving`에 전달돼 목록이 다시 조회된다. 백엔드 매핑: `category→category_large`, `ooh_type`, `exposure_type`, `media_shape`는 `IN` 조건, `product_master_type`(매체 판매 유형)은 해당 매체 **플랜**의 유형 집합으로 조인 필터, `price_min/max`는 `min_advertisement_fee_krw` 범위.
- `❓` `매체 판매 유형` 칩 라벨은 프런트에서 `saleType`으로 부르고 API 파라미터는 `product_master_type`으로 매핑되는데, 이동매체 데이터에 이 옵션/플랜이 실제로 존재하는지(옵션이 비어 있을 가능성) 미확인.

### 3.3 매체 카드 목록
- **기능**: 필터 결과 이동매체를 카드 그리드로 표시.
- **규칙**:
  - 그리드: 모바일 2열, `sm` 이상은 `auto-fill`(최소 228px) 다열.
  - **정렬**: `media_id` 오름차순(백엔드 `order_by(Media.media_id)`).
  - **페이지네이션 없음**: `GET /media/moving`은 limit/offset이 없어 조건에 맞는 **전체 목록**을 한 번에 반환한다(고정매체의 무한스크롤과 다름).
  - 각 카드 = 썸네일 이미지 + 매체명 + 최소집행금액 + (뱃지).
    - **금액 표시**: `minAdvertisementFeeKrw`가 있으면 `최소집행금액 N만원`(원→만원, 반올림, 천단위 콤마), null이면 `최소집행금액 협의`.
    - **뱃지**: `popular`→"인기", `new`→"신규". 없으면 미표시.
    - 이미지가 없으면 회색 플레이스홀더만 표시.
  - **카드 클릭**: 해당 매체를 선택(`selectedId`)하고 우측 상세를 연다(`detailOpen=true`). 선택된 카드는 배경 강조.
- `❓` `popular`/`new` 뱃지 노출 기준(데이터 플래그) 및 결과 0건일 때의 빈 상태 표시.

### 3.4 매체 상세 (우측 영역)
- **기능**: 선택한 매체의 상세 정보. `GET /media/{id}` 응답으로 채운다.
- **규칙**:
  - 선택된 매체가 없으면 목록의 **첫 매체**를 기본 선택(`selected = ... ?? mediaList[0]`).
  - `sm` 이상: `MediaDetailContent`(우측 패널) 표시. `sm` 미만: `MobileMediaDetail`로 전체 화면 전환, 뒤로가기(`onBack`) 시 `detailOpen=false`로 목록 복귀.
  - 표시 항목: 이미지(썸네일 우선, 없으면 첫 이미지) · 매체명 · 금액(목록과 동일 포맷 문자열 전달) · 뱃지 · 설명 · features(라벨/값 목록) · 요금제(plans: 제목/부제/planNo) · 사이즈 텍스트.
  - **유동인구 데이터는 숨김**: 두 상세 컴포넌트 모두 `hidePopulation`으로 호출 → 이동매체는 성별/연령/유동인구 블록을 노출하지 않는다(고정매체와 차이).
  - 상세 화면 이동(`/media/[id]`) 버튼 등 하위 인터랙션은 공용 `MediaDetailContent` 정책을 따름.
- `❓` 이동매체 상세에 요금제/사이즈/features가 실제로 채워지는지(데이터 존재 여부) 미확인.

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 기본 | 최초 진입 | 위치 검색 + 필터바 + 카드 목록, 우측(또는 sm이상)에 첫 매체 상세 |
| 상세 선택 | 카드 클릭 | 선택 카드 강조 + 해당 매체 상세로 우측 갱신 (모바일은 상세 전환) |
| 모바일 목록↔상세 | `sm` 미만 | 목록/상세가 화면을 번갈아 차지, 뒤로가기로 복귀 |
| 결과 없음 | 필터 결과 0건 | ❓ (전용 빈 상태 UI 미확인, 상세는 `mediaList[0]` 없어 렌더 안 됨) |
| 로딩 / 에러 | 조회 중 / 실패 | ❓ (전용 처리 미확인) |

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 · 비고 |
|---|---|---|
| 매체 카드 목록 | `GET /media/moving` (필터 쿼리) | 진입 시 + 필터 변경 시. limit/offset 없음(전체) |
| 필터 옵션 | `GET /media/moving/filter-options` | 진입 시. MOVING distinct 값 + 가격 범위/히스토그램 |
| 매체 상세 | `GET /media/{id}` | 선택 매체 있을 때(`enabled`), 첫 진입 시 첫 매체 자동 조회 |

React Query staleTime: 목록/상세 60초, 필터 옵션 5분.
