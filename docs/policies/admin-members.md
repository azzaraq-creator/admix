## 1. 목적

관리자가 가입 회원을 목록으로 조회·검색하고, 회원별 상세(기본 정보·제안 이력·문의 이력·제재 이력)를 확인한다. 상세의 기본 정보 탭에서 회원 프로필 일부(직책·업종·운영자 메모)와 **사업자 등록 정보(상태·사업자명·등록번호·주소·업태·반려 사유)**를 수정한다.

- 핵심 사용자: `member` 권한을 가진 관리자 또는 마스터 계정
- 성공 기준: ❓

## 2. 권한

`/admin/members` 전 엔드포인트는 백엔드 가드 `require_permission("member")`로 보호된다. 마스터 계정은 권한 설정과 무관하게 전체 허용, 일반 관리자는 `member` 권한 보유 시에만 접근한다(미보유 시 API 403). 사이드바 메뉴 노출도 동일 권한 기준(`canSee`). 상세 규칙은 [관리자 인증·권한 정책](admin-auth-permissions.md) §3 참조.

| 사용자 | 접근 | 비고 |
|---|---|---|
| 마스터 계정 | 목록·상세·수정 전부 | 권한 설정 무관 전체 허용 |
| `member` 권한 관리자 | 목록·상세·수정 전부 | 권한 없으면 메뉴 숨김 + API 403 |
| 그 외 관리자 | 접근 불가 | 403 |

> 목록/상세/수정 사이에 세부 권한 구분은 없다 — 네 엔드포인트(GET 목록·GET 상세·PATCH 회원·PATCH 사업자등록) 모두 동일하게 `member` 권한만 요구.

## 3. UI 블록

### 3.0 목록 — 페이지 헤더

- **기능**: 화면 제목 "회원 관리" 표시.
- **규칙**: 정적 텍스트. 별도 동작 없음.

### 3.1 목록 — 검색/필터 바

- **기능**: 회원 목록을 조건으로 좁힌다. `CommonTable`의 검색 옵션으로 구성.
- **규칙**: 필터는 아래 5개. **모두 클라이언트 측 필터링**(목록 API는 전체를 한 번에 내려주고, 브라우저에서 걸러냄).
  - **기간(dateRange, `period`)**: UI에 노출되나 현재 필터 로직에 **연결돼 있지 않음** — 실제 조회 결과에 영향 없음 ❓.
  - **사업자 인증 상태(select, `bizStatus`)**: 미등록 / 검토 대기 / 검토 완료 / 인증 반려 — 완전 일치.
  - **상태(select, `status`)**: 정상 / 탈퇴 / 제재 / 휴면 — 완전 일치.
  - **유형(select, `type`)**: 일반 / 기업 — 완전 일치.
  - **키워드(text, `keyword`)**: **이름 또는 이메일**에 대한 부분 일치(`includes`). 회사명·전화번호는 검색 대상 아님.
  - 여러 필터는 AND 결합. 빈 값은 무시.

### 3.2 목록 — 상단 우측 액션 (엑셀 다운로드)

- **기능**: "엑셀 다운로드" 버튼.
- **규칙**: 테이블 우측 상단에 노출되나 **onClick 핸들러가 연결돼 있지 않음 → 클릭해도 동작 없음(플레이스홀더)** ❓.

### 3.3 목록 — 총건수 / 페이지당 개수

- **기능**: 필터 적용 후 총 건수 표시 + 페이지당 표시 개수 선택.
- **규칙**: 총건수 = 필터링된 결과 수(`filtered.length`). 페이지 크기 기본 10, `usePageSizeSelect`로 변경 가능(옵션 값은 `CommonTable` 정의를 따름).

### 3.4 목록 — 테이블

- **기능**: 회원 목록 표. 컬럼: No · 회원 유형 · 회사명 · 이름 · 이메일 · 전화번호 · 사업자 인증 상태 · 마케팅 수신 · 가입일.
- **규칙**:
  - **정렬**: 백엔드에서 가입일(`created_at`) 내림차순 고정. 컬럼 클릭 정렬 없음.
  - **No 컬럼**: DB PK가 아니라 **현재 필터링된 목록 내 순번(1부터)**. 필터에 따라 값이 바뀜.
  - **사업자 인증 상태**: 배지로 표시(상태별 색). 사업자등록 정보 없으면 "미등록".
  - **마케팅 수신**: 동의 / 비동의.
  - **행 클릭**: `/admin/members/{id}`로 이동. 여기서 `id`는 회원 UUID(`no` 필드에 UUID가 담김).
  - 빈 값 필드는 백엔드에서 "-"로 치환.

### 3.5 상세 — 헤더 카드

- **기능**: 회원 요약(이름·회원 유형·사업자정보 배지·가입일) + 제안/문의 건수.
- **규칙**:
  - 아바타는 고정 아이콘(빌딩 아이콘). 이미지 업로드 없음.
  - 회원 유형: `corporate`→기업 / `individual`→일반 매핑.
  - 사업자정보 배지: 사업자등록 상태를 한글로 표시, 없으면 "미등록".
  - 가입일: `created_at`의 날짜(앞 10자).
  - 제안 건수/문의 건수: 해당 회원의 제안·문의 개수.

### 3.6 상세 — 탭 네비게이션

- **기능**: 기본 정보 / 제안 이력 / 문의 이력 / 제재 관리 4탭 전환.
- **규칙**: 기본 활성 탭 = 기본 정보. 클릭 시 아래 콘텐츠 영역만 교체(클라이언트 상태, 라우팅 변화 없음).

### 3.7 상세 — 기본 정보 탭

- **기능**: 회원 기본 정보 조회 + 일부 필드 수정 + 사업자 등록 정보 수정 + 운영자 메모.
- **규칙**:
  - **읽기 전용(수정 불가)**: 회원 유형, 회사명, 이름, 이메일, 전화번호, 가입일, 탈퇴일, 마케팅 수신.
    - 탈퇴일: `withdrawn_at` 날짜, 없으면 "-".
  - **수정 가능(회원 프로필, PATCH `/admin/members/{id}`)**: 직책(`position`), 업종(`industry`), 운영자 메모(`admin_memo`). 저장 시 공백 트림 후 빈 문자열이면 `null`로 전송.
  - **사업자 등록 정보 카드(수정 가능, PATCH `/admin/members/{id}/business-registration`)**:
    - **상태**(필수 표시 `*`): Select — 미등록 / 검토 대기 / 검토 완료 / 인증 반려. 기본값 미등록. (admin은 `reviewing`을 **"검토 대기"**로 표기 — 유저단 마이페이지는 동일 상태를 "검토중"으로 표기, profile §3.4)
    - 사업자명·사업자등록번호·주소·사업의 종류(업태/종목)·반려 사유: 텍스트 입력. 트림 후 빈값 `null`.
    - **등록증 파일(조회 전용, Figma 1198:26350)**: 회원이 업로드한 파일이 있으면 카드 하단에 **미리보기**(이미지→`<img>`, PDF→`<iframe>`, 323×447) + **파일 정보 행**(공용 `LicenseFileInfo` — 아이콘 + 원본 파일명 + 업로드 시각) + **다운로드 버튼**. 다운로드는 인증 엔드포인트 `GET /admin/members/{id}/business-registration/download`에서 blob으로 받아 **원본 파일명**으로 저장(`FileResponse`가 `Content-Disposition` 지정, CORS 무관). 없으면 "등록된 파일이 없습니다." 파일 업로드는 회원 본인이 마이페이지/가입에서 수행하며(profile §3.4) admin은 조회·다운로드만 한다.
    - 회원에게 사업자등록 레코드가 없으면 저장 시 백엔드가 `unregistered` 상태로 신규 생성.
    - 상태를 `verified`(검토 완료)로 저장하고 기존 `verified_at`이 없으면 백엔드가 인증 시각을 자동 기록.
  - **저장 버튼(하단 우측)**: 회원 PATCH → 사업자등록 PATCH를 **순차 2회 호출**. 둘 다 성공 시 "저장 완료" 알림, 실패 시 에러 메시지 알림. 저장 중 버튼 비활성.
  - **목록으로 버튼(하단 좌측)**: `/admin/members`로 이동.

### 3.8 상세 — 제안 이력 탭

- **기능**: 회원이 등록한 제안서 목록.
- **규칙**: 컬럼 No · 제안서 명 · 이름 · 전체 금액 합계 · 상태 · 등록일. 검색 없음, 페이지 크기 10. 최신 등록순(`created_at` 내림차순). 금액은 `1,000원` 형식. 상태: 취소/신규/맞춤제안/집행요청/계약 완료(백엔드 매핑) — 단, 프론트 상태 배지 색상 정의에는 취소·신규·맞춤제안·계약 완료만 있어 "집행요청"은 배지 색이 정의되지 않음 ❓.

### 3.9 상세 — 문의 이력 탭

- **기능**: 회원이 남긴 문의 목록.
- **규칙**: 컬럼 No · 이름 · 제목 · 문의 내용 · 상태 · 제출일. 문의 내용은 최대 폭에서 말줄임. 검색 없음, 페이지 크기 10. 최신순. 상태: 답변 대기 / 답변 완료.

### 3.10 상세 — 제재 관리 탭

- **기능**: 회원 제재 이력 표시.
- **규칙**: 컬럼 No · 제재 이력(사유) · 제재 일자(`start_date`) · 제재 종료(`end_date`, 없으면 "-"). 제재 시작일 내림차순. **조회 전용** — 이 화면에서 제재 추가/해제/편집 기능은 없음(생성·수정 API 미제공) ❓.

> 제재/회원 상태(정상·탈퇴·제재·휴면) 변경: 회원 상태(`status`)는 백엔드 `MemberUpdate`로 변경 가능하고(`withdrawn` 전환 시 `withdrawn_at` 자동 세팅/해제), 목록 필터에도 상태가 있으나 **현재 상세 UI에는 회원 상태를 바꾸는 입력이 노출돼 있지 않다** ❓.

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 목록 로딩 | 목록 조회 중 | `CommonTable`에 `data?.items ?? []`(빈 배열) 전달 — 별도 로딩 UI ❓ |
| 목록 결과 | 데이터 있음 | 필터 반영 테이블 |
| 목록 결과 없음 | 필터 0건 | 총건수 0, 빈 테이블 (전용 빈 상태 문구 ❓) |
| 상세 로딩 | 상세 조회 중(`member` 없음) | "불러오는 중..." 텍스트 |
| 상세 결과 | 데이터 있음 | 헤더 카드 + 탭 |
| 저장 진행 | 저장 mutation 중 | 저장 버튼 비활성 |
| 저장 완료/실패 | mutation 결과 | 관리자 알림(`useAdminConfirm`) — 완료/실패 메시지 |
| 에러 | 조회 실패 | 상세는 계속 "불러오는 중..."에 머무름(에러 전용 처리 없음) ❓ |

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 · 비고 |
|---|---|---|
| 회원 목록 | `GET /admin/members` | 목록 진입. 전체 반환(서버 페이지네이션·검색 없음), staleTime 30초 |
| 회원 상세 | `GET /admin/members/{id}` | 상세 진입. users + business_registration(1:1) + sanctions + proposals + inquiries |
| 회원 프로필 수정 | `PATCH /admin/members/{id}` | 저장 시. `exclude_unset` 부분 업데이트, status=withdrawn 시 `withdrawn_at` 자동 처리 |
| 사업자등록 수정 | `PATCH /admin/members/{id}/business-registration` | 저장 시. 레코드 없으면 신규 생성, verified 전환 시 `verified_at` 자동 |
| 등록증 파일 다운로드 | `GET /admin/members/{id}/business-registration/download` | 다운로드 버튼. `FileResponse`(원본 파일명 attachment) |
| 캐시 무효화 | React Query | 수정 성공 시 목록·해당 상세 쿼리 invalidate |
| 엑셀 다운로드 | 미연동 | 버튼만 존재, 핸들러 없음 ❓ |

## 6. 미정 (Open Questions / 결정 로그)

**미결정**

- [ ] 목록 "기간(period)" 날짜 필터가 실제 필터 로직에 연결돼 있지 않음 — 가입일 기준 필터로 구현할지 결정 필요.
- [ ] "엑셀 다운로드" 버튼 동작 사양(대상 데이터·형식·서버/클라이언트 생성) — 현재 핸들러 미연결 플레이스홀더.
- [ ] 회원 상태(정상/탈퇴/제재/휴면) 변경을 상세 화면 어디서 어떻게 하는지 — 백엔드는 지원하나 UI 입력 없음.
- [ ] 제재 관리 탭의 제재 추가/해제/편집 기능 여부 — 현재 조회 전용, 생성·수정 API 없음.
- [ ] 제안 상태 "집행요청(execution_requested)" 배지 색상 미정의 — 프론트 상태 색상 맵에 누락.
- [ ] Figma 프레임(목록·상세·상태별) 링크 — 미확인.
- [ ] 목록 로딩/결과 없음/에러 전용 상태 UI 문구.
