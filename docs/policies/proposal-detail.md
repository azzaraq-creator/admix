## 1. 목적
고객이 담아둔 매체로 만들어진 제안서를 **슬라이드(표지·서머리·매체별·THANK YOU) 덱**으로 보고, 매체 순서·플랜·수량·기간을 편집한 뒤 **제출(집행 요청)**하는 화면이다. 관리자가 맞춤제안(역제안) PPT를 올린 제안서는 편집 대신 **맞춤제안 덱 뷰어**로 전환되어 변환된 슬라이드를 열람·다운로드한다.

- 핵심 사용자: 옥외광고 매체를 담아 집행을 검토하는 광고주/마케터 (비회원 세션 포함)
- 성공 기준: ❓ (예: 제안서 제출 전환율 — 미정)

## 2. 권한

이 화면은 **한 라우트가 상태에 따라 두 뷰로 분기**한다. `status === "custom"` 이고 변환된 맞춤제안 슬라이드(`counter_proposal_slides`)가 1장 이상이면 **맞춤제안 덱 뷰**(`CounterProposalDeckView`), 그 외에는 **편집 뷰**(`ProposalEditorView`).

소유·접근은 백엔드가 `(member_id, session_id)`로 판정한다. 회원은 토큰, 비회원은 `session_id`로 자기 제안서만 조회/수정 가능(소유 아니면 404). 매체 담기·순서변경·이름변경·삭제는 회원·비회원 모두 가능하지만, **제출/제출취소는 회원 전용**(백엔드 `get_current_user` 강제).

| 사용자 | 접근 | 편집(순서·플랜·수량·기간·삭제) | 제출/제출취소 | 제안서 개수 한도 |
|---|---|---|---|---|
| 비회원(guest, session) | 자기 세션 제안서 | O | X (로그인 유도 모달) | 1개 (`GUEST_LIMIT`) |
| 일반 회원(member) | 자기 제안서 | O | O | 5개 (`MEMBER_LIMIT`) |
| 인증 회원(verified) | 자기 제안서 | O | O | 무제한 |

> 개수 한도는 **제안서 생성 시점**(다른 화면)에서 걸리며, 초과 시 백엔드가 409 `{reason:"limit_reached", tier, limit}` 반환. 이 상세 화면 자체에는 개수 한도 UI가 없다.
> 상태가 `execution_requested`(제출완료) 또는 `contracted`(계약완료)면 편집 뷰가 **잠금(locked)**된다(아래 3, 4 참조).

---

## 3. UI 블록

화면은 크게 **① 상단 헤더 → ② 좌측 슬라이드 사이드바 → ③ 우측 미리보기(줌/전체보기) → ④ 전체보기 라이트박스(모달)** 로 구성된다. 아래 3.0~3.6은 **편집 뷰**, 3.7은 **맞춤제안 덱 뷰**, 3.8은 공통 모바일 차단.

### 3.0 상단 헤더 (편집 뷰)
- **기능**: 제안서명·상태·최종수정 표시 + 이름수정·내보내기·제출/제출취소·삭제 액션.
- **규칙**:
  - **제안서명**: 텍스트 옆 연필 아이콘 클릭 시 인라인 입력으로 전환. `Enter`(한글 조합 중 제외) 또는 blur 시 확정. 값이 비었거나 기존과 같으면 저장 호출 안 함, 다르면 `PATCH /proposals/{id}` 로 rename. **잠금 상태면 연필 아이콘 숨김.**
  - **상태 칩**: 백엔드 raw status → 고객 라벨 매핑 — `new`=작성중, `execution_requested`=제출완료, `custom`=맞춤제안, `contracted`=계약완료, `cancelled`=취소. (관리자 화면은 별도 라벨 — `execution_requested`="신규")
  - **최종 수정**: `updated_at` 를 `YYYY.MM.DD HH:mm` 로 표시(없으면 `-`).
  - **내보내기 버튼**: 노출되나 **onClick 핸들러가 연결돼 있지 않아 현재 아무 동작도 하지 않는다** (`exportPpt` 클라이언트 API는 존재하지만 편집 뷰에서 미연결). ❓
  - **제출/제출취소 버튼**(상태 분기):
    - `execution_requested` → `제출취소` 버튼. 클릭 시 확인 모달("제출을 취소하시겠습니까?") 후 `POST /proposals/{id}/cancel` → 상태 `new` 복귀(작성중, 재편집 가능).
    - 잠금 아님(`new` 등) → `제출하기` 버튼. **비회원이면** "제안서 제출은 로그인 후 이용 가능해요" 모달 → 확인 시 로그인 모달 오픈. **회원이면** "제안서를 제출하시겠습니까?"(제출 후 수정 불가 안내) 확인 후 `POST /proposals/{id}/submit` → 상태 `execution_requested`.
    - 잠금(`contracted`) → 제출/제출취소 버튼 모두 미노출.
  - **삭제 버튼**(휴지통): 확인 모달("제안서를 삭제하시겠습니까?", destructive) 후 `DELETE /proposals/{id}` → `/proposals` 로 이동. 잠금 여부와 무관하게 항상 노출(계약완료도 삭제 가능).
    - **삭제 처리(상태별)**: `new`=완전삭제 / `execution_requested`·`custom`=`cancelled`(취소) 전환 / `contracted`=상태 유지 + `deleted_at` 기록. 삭제 후 유저 목록·상세에서 사라진다. 관리자 노출 규칙은 [admin-proposals.md](admin-proposals.md), 요약은 [proposals.md](proposals.md) 3.3.2.

### 3.1 좌측 슬라이드 사이드바 (편집 뷰)
- **기능**: 덱의 전체 슬라이드 썸네일 목록 + 순서변경·삭제 + 매체추가.
- **규칙**:
  - 상단에 `슬라이드 N`(총 개수) 표시.
  - **슬라이드 구성(고정 순서)**: `표지(cover)` → `서머리 1..N` → `매체 슬라이드(담은 매체 순서)` → `THANK YOU(thanks)`.
    - 서머리는 **매체 5개당 1장**(`SUMMARY_PAGE_SIZE=5`)으로 분할, 2장 이상이면 이름이 "서머리 1/2…". 매체가 0개여도 빈 서머리 1장은 유지.
  - **선택**: 썸네일 클릭 시 우측 미리보기에 해당 슬라이드 렌더. 선택 슬라이드는 파란 링 표시.
  - **순서변경(드래그)**: **매체 슬라이드끼리만** 가능. 표지·서머리·THANK YOU는 고정(드래그 핸들 없음). 잠금 상태면 전체 드래그 불가. 드롭 시 로컬 `mediaOrder`만 갱신(저장은 3.2 저장하기).
  - **슬라이드 삭제**: 매체 슬라이드 썸네일 우상단 휴지통 → 확인 모달("N-매체명 가 제안서에서 삭제됩니다") 후 `DELETE /proposals/{id}/items/{mediaId}`. 고정 슬라이드·잠금 상태에서는 삭제 버튼 없음.
  - **매체추가 버튼**: 하단 고정, `/fixed`(고정매체 탐색)로 이동. 잠금 상태면 숨김.

### 3.2 미리보기 상단 바 (편집 뷰)
- **기능**: 최종 수정 시각 + 저장하기.
- **규칙**:
  - **저장하기 버튼**: 잠금 아닐 때만 노출. 클릭 시 현재 매체 순서 + 변경된 플랜(`selectedPlans`)·기간(`selectedDates`)·수량(`selectedQuantities`)을 모아 `PUT /proposals/{id}/order` 로 저장. 매체가 0개면 저장 호출 없이 "저장이 완료되었습니다" 토스트. 성공 시 로컬 편집 상태 초기화(서버 응답으로 재조회). 요청 중 버튼 비활성.

### 3.3 미리보기 영역 — 슬라이드 렌더 (편집 뷰)
- **기능**: 선택된 슬라이드 1장을 실제 템플릿으로 렌더(1920×1080 스케일). 슬라이드 종류별로 인라인 편집 가능.
- **규칙**:
  - **표지 슬라이드**: `updated_at` 반영 표지 템플릿(정적).
  - **서머리 슬라이드**(`SummaryTemplate`): 상단에 캠페인 기간·집행 매체 수·캠페인 지역·광고비/제작비 합계·전체 금액 합계(GROSS, VAT 별도) + 매체 표(NO/구분/지역/매체명/상품명/수량/광고비/제작비/합계/시작일·종료일).
    - **수량 입력**: 숫자만(비숫자 제거). 잠금 아니면 편집 가능 → `selectedQuantities` 반영, 저장 시 서버 전송. **기본값 1**(미입력·0 은 1 로 간주). 편집 중엔 빈칸 허용(placeholder `1`), 읽기전용/PPT 는 1 로 표시.
    - **수량×단가 계산**: 표의 광고비 = `광고단가 × 수량`, 제작비 = `제작단가 × 수량`, 행 합계 = `(광고+제작) × 수량`. 상단 광고비/제작비 합계·GROSS 도 모두 수량 반영. 저장 시 `total_amount = Σ(광고단가 × 수량)` 로 재계산(`_recount` — 순서/플랜/수량 저장 경로 `reorder_items` 에서 호출). PPT 내보내기도 동일 반영.
      - GROSS(`total_amount`)는 **제작비 미포함**(광고비 합계와 동일)이 기존 정의. 저장/PPT GROSS 는 스냅샷 `proposal_item.price`(담을 때 min 광고요금) 기반이라, 기본이 아닌 플랜을 고른 제안서에선 화면 GROSS(선택 플랜요금×수량)와 어긋날 수 있음(수량 도입 이전부터 있던 불일치).
    - **날짜 입력**(시작일/종료일): 텍스트 입력(placeholder `YYYY.MM.DD`). 잠금 아니면 편집 가능 → `selectedDates` 반영. **날짜 형식·달력 피커 연동 여부** ❓ (현재 자유 텍스트, `CalendarIcon`은 장식).
    - 합계/캠페인 기간/지역은 편집값을 실시간 반영해 재계산.
  - **매체 슬라이드**(`MediaTemplate`): 매체명·메타(주소/유형/카테고리)·설명·대표 이미지·지도(좌표 있으면 카카오 정적지도, 없으면 "위치 정보 없음") + 상품 표(상품명/노출회수/판매수량/규격/운영시간/기간/광고비/제작비용).
    - **플랜 Select**: 플랜이 2개 이상이고 잠금 아니면 상품명 셀이 Select로 노출 → 선택 시 `selectedPlans` 반영, 매체명·상품명·광고비·제작비가 즉시 갱신되고 서머리에도 반영. 플랜 1개면 텍스트로만 표시.
    - **노출회수·기간 셀은 현재 `-` 고정 표시**(값 미연동). ❓
  - **THANK YOU 슬라이드**: 정적.
  - 데이터/템플릿 매칭 실패 시 `/proposals/sample.png` 플레이스홀더 이미지 표시.
  - **그랩-드래그 팬**: 확대로 넘친 슬라이드를 마우스로 끌어 이동. 이동량이 5px 임계값을 넘을 때만 팬으로 인식 → 단순 클릭(Select·입력)은 그대로 통과.

### 3.4 줌/전체보기 컨트롤 (편집 뷰, 하단 플로팅)
- **기능**: 전체보기 진입 + 확대/축소.
- **규칙**:
  - **전체보기 아이콘**: 현재 선택 슬라이드를 시작 인덱스로 라이트박스(3.6) 오픈.
  - **확대/축소**: `25%`~`200%`, 단계 `25%`. 현재 배율 숫자 표시. 편집·맞춤제안 뷰 공통 규격.

### 3.5 전체 화면 상태 배지
(별도 UI 없음 — 상태는 3.0 헤더 상태 칩으로만 노출.)

### 3.6 전체보기 라이트박스 (편집 뷰, 모달 `SlideLightbox`)
- **기능**: 슬라이드를 큰 화면으로 넘겨보는 오버레이.
- **규칙**:
  - `Esc` 닫기, `←/→` 이동, 좌우 화살표 버튼(양 끝에서 비활성), 하단 `현재/전체` 카운터.
  - 하단 썸네일 스트립: 클릭 이동, 현재 슬라이드 자동 스크롤 노출.
  - 렌더는 편집 뷰와 같은 템플릿을 재사용하되 **매체 슬라이드 지도는 큰 화면에서만 활성**(썸네일에선 지도 비활성).

### 3.7 맞춤제안 덱 뷰 (`status=custom` + 슬라이드 존재)
- **기능**: 관리자가 올린 맞춤제안 PPT를 변환한 이미지 슬라이드를 열람·다운로드(편집 불가).
- **규칙**:
  - **헤더**: 제안서명 + 상태 칩(`맞춤제안`) + 최종수정. 이름수정·제출·삭제 버튼 없음.
  - **내보내기 버튼**: 클릭 시 `GET /proposals/{id}/counter-proposal/download` 로 **원본 PPTX** 다운로드(파일명 `counter_proposal_file_name`, 없으면 `맞춤제안.pptx`).
  - **좌측 사이드바**: 슬라이드 총 개수 + 썸네일 목록(번호·클릭 선택). 이미지는 `{API_BASE}{slides_url}/{thumb}` 에서 로드.
  - **중앙 미리보기**: 선택 슬라이드 원본 이미지(`{slides_url}/{image}`), 줌 25~200%(3.4와 동일 규격).
  - **전체보기**: `ImageLightbox` 모달로 슬라이드 이미지 순회(초기 인덱스=현재). `Esc` 닫기.
  - 슬라이드 이미지·메타는 백엔드가 변환 시 만든 `meta.json`(`slides:[{image,thumb}]`)에서 읽는다. 변환 실패 시 슬라이드 0장 → 편집 뷰로 폴백(분기 조건 미충족).

### 3.8 모바일 미지원 안내 (공통)
- **기능**: 640px 미만(`sm` 미만)에서 기능 차단.
- **규칙**: 화면 전체에 "해당 기능은 모바일에서 지원되지 않습니다. 데스크톱으로 이용해주시기 바랍니다." 오버레이. 편집 뷰는 닫기 버튼 클릭 시 `/proposals` 로 이동, 맞춤제안 덱 뷰는 닫기 버튼 없이 안내만.

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 편집(작성중) | `status=new` (또는 슬라이드 없는 custom) | 전체 편집 가능(순서·플랜·수량·기간·삭제·저장), 제출하기 노출 |
| 제출완료 | `status=execution_requested` | 편집 잠금, 헤더에 `제출취소` 노출, 저장·매체추가·삭제(슬라이드)·드래그 불가 |
| 계약완료 | `status=contracted` | 편집 잠금, 제출/제출취소 버튼 미노출(제안서 삭제 버튼은 유지) |
| 맞춤제안 덱 | `status=custom` + 변환 슬라이드 ≥1 | 편집 UI 대신 맞춤제안 덱 뷰(열람·원본 PPTX 다운로드) |
| 취소(삭제됨) | `status=cancelled` 또는 `deleted_at` 존재 | 유저 목록·상세에서 제외(`get_owned` 404). 고객은 이 화면에 도달하지 않음 |
| 매체 0개 | items 없음 | 표지+빈 서머리+THANK YOU만, 저장은 API 호출 없이 토스트 |
| 로딩 / 에러 | 상세 조회 중·실패 | ❓ (별도 스켈레톤/에러 UI 미확인) |
| 모바일 | 뷰포트 <640px | 미지원 오버레이(3.8) |

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 · 비고 |
|---|---|---|
| 제안서 상세(제목/상태/items/합계/맞춤제안 슬라이드) | `GET /proposals/{id}` (`useProposalDetail`) | 진입 시. 비회원은 `session_id` 쿼리 |
| 이름 변경 | `PATCH /proposals/{id}` | 헤더 인라인 편집 확정 시 |
| 순서·플랜·수량·기간 저장 | `PUT /proposals/{id}/order` | 저장하기 클릭 |
| 슬라이드(매체) 삭제 | `DELETE /proposals/{id}/items/{mediaId}` | 썸네일 휴지통 확인 후 |
| 제출 / 제출취소 | `POST /proposals/{id}/submit` · `/cancel` | 회원 전용(토큰). 취소는 `execution_requested`만 허용 |
| 제안서 삭제 | `DELETE /proposals/{id}` | 헤더 휴지통 확인 후 → `/proposals` 이동. 상태별 분기(완전삭제/취소전환/상태유지+삭제됨) |
| 맞춤제안 원본 PPTX 다운로드 | `GET /proposals/{id}/counter-proposal/download` | 맞춤제안 덱 뷰 내보내기 |
| 맞춤제안 슬라이드 이미지 | `{NEXT_PUBLIC_API_URL}{slides_url}/{image|thumb}` 정적 파일 | 관리자 업로드 시 PPT→이미지 변환(`meta.json`) |
| 매체 지도 | 카카오 정적지도(`StaticKakaoMap`) | 매체 슬라이드에 좌표 있을 때 |
| (미연결) 내 제안서 PPT 생성 | `GET /proposals/{id}/export-ppt` (`exportPpt`) | API·백엔드 존재하나 편집 뷰 "내보내기" 버튼에 미연결 ❓ |
