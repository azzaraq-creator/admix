## 1. 목적
좌측 패널에서 **AI 추천 또는 매체 검색**으로 옥외광고 매체를 찾고, 우측 지도에서 매체 위치를 함께 확인하는 지도 기반 탐색 화면이다. 매체를 골라 상세 정보를 보고 제안서로 이어가는 흐름의 중심 화면이다.

- 핵심 사용자: 옥외광고 매체를 찾는 광고주/마케터
- 성공 기준: ❓ (예: 매체 카드 클릭률, 상세 → 제안서 담기 전환율 — 미정)

## 2. 권한
접근 권한은 **전체 사용자**(비회원 포함). AI 매체추천 채팅 사용량은 사용자 등급별 **채팅 토큰**으로 제한하며, 정책은 AI 매체추천 정책서(`ai-media-recommend.md`)를 따른다. 단, 참고 PRD([1422-31386])에는 비회원 30회 / 일반회원 100회 / 인증회원 무제한으로 적혀 있어 기존 정책서(비회원 5회)와 수치가 다르다 → **미정** 참조.

## 3. UI 블록 (위 → 아래 / 좌 → 우)

화면은 좌측부터 **① LNB 레일 → ② 좌측 패널(채팅/검색) → ③ 매체 상세 드로어(선택 시) → ④ 지도** 순으로 가로 배치된다.

### 3.1 LNB 레일 (사이드바)
- **무엇**: 고정/이동·지역 매체, 서비스 소개, 내 제안서, 문의하기, 도움말, 로그인 진입 아이콘 레일.
- **동작 규칙**:
  - 기본은 접힘(아이콘만). 클릭 시 펼침(라벨 노출).
  - 펼치면 **좌측 패널만 우측으로 밀리고, 지도는 리사이즈되지 않고 덮인다.** (지도는 고정, 패널이 그 위를 덮음)
  - "고정 매체" 항목은 현재 화면이므로 활성 표시.

### 3.2 모드 토글 (AI 매체추천 / 매체 검색)
- **무엇**: 좌측 패널 상단의 2분할 토글.
- **동작 규칙**:
  - 기본값 **AI 매체추천**.
  - 토글로 좌측 패널 본문이 AI 추천 뷰 ↔ 매체 검색 뷰로 전환된다.

### 3.3 AI 매체추천 뷰
- **무엇**: 인사말 + 추천 예시(FAQ) + 채팅 입력.
- **동작 규칙**:
  - **추천 예시**: 리스트 클릭 시 해당 문구가 입력창에 자동 입력된다. (전송까지 자동 처리 여부 ❓)
  - **채팅 입력**: 최대 **500자**, 최대 **5행**까지 높이 증가 후 그 이상은 스크롤.
  - 전송 시 사용자 발화 등록 + AI 추천 요청.
  - 추천 결과는 패널 본문에 리스트로 노출되며, **리스트 자체가 아니라 채팅방(패널 본문)이 스크롤**된다.

### 3.4 매체 검색 뷰
- **무엇**: 위치 검색 입력 + 필터바 + 결과 매체 목록.
- **동작 규칙**:
  - **위치 검색 입력**: 홈의 위치 검색 입력과 동일 컴포넌트 재사용.
  - **필터바(접힘)**: `초기화` + 카테고리·가격 범위·매체 판매 유형·매체 타입·설치 장소·매체 형태 칩이 가로로 나열. **스크롤바 없이 잡아끌어(그랩 드래그) 가로 스크롤**. 우측 chevron으로 펼침.
  - **필터바(펼침)**: 2열 그리드로 6개 필터 + 하단 `초기화`/접기(chevron-up). chevron으로 접힘↔펼침 토글.
  - **결과 목록**: 매체 카드 리스트. 패널 본문이 스크롤.

### 3.5 매체 카드 (목록 항목)
- **무엇**: 사진 3장 + 매체명 + 최소집행금액/집행단위 + 제안서 담기 버튼(+ 인기 뱃지).
- **동작 규칙**:
  - **간략히보기 토글** 시 이미지 숨김.
  - **제안서 담기 버튼**: 제안서에 매체 추가(모달 ❓). 카드 클릭과 별개로 동작(전파 차단).
  - **카드 클릭 시 매체 상세 드로어 노출.**
  - 인기 뱃지는 노출 기준 미정 → prop으로만 구현(현재 퍼블리싱). **미정** 참조.

### 3.6 지도
- **무엇**: 매체 위치 마커 + 현재 위치 버튼.
- **동작 규칙**:
  - 좌측 패널/드로어/LNB 펼침에 따라 좌측이 덮이며, 지도 자체는 리사이즈되지 않는다.
  - 마커 아이콘은 데이터(매체 유형 등)에 따라 다르게 표시 예정 ❓. (실지도 연동 별도)

### 3.7 매체 상세 드로어
- **무엇**: 매체 카드(또는 지도 마커 항목) 클릭 시 좌측 패널 우측에 열리는 상세 패널.
- **구성**: 이미지 영역(닫기 X) · 기본 정보(매체명/금액/월평균 유동인구수/주요 인구층/매체 담기) · 위치 · 매체 설명(3줄 + 더보기) · 유동 인구 데이터(성별·연령 비율, 데이터 없으면 hide).
- **동작 규칙**:
  - **닫기(X)** 클릭 시 드로어 닫힘.
  - **자세히** 클릭 시 매체 상세 화면(`/media/[id]`)으로 이동.
  - 이미지 클릭 시 전체보기 오버레이 ❓(미구현).

### 3.8 패널 접기 핸들 (chevron)
- **무엇**: 좌측 패널(과 드로어) 우측 가장자리의 접기/펼치기 탭.
- **동작 규칙**:
  - 클릭 시 좌측 패널을 접고/펼친다.
  - **상세 드로어까지 펼쳐진 상태에서 접기(`채팅 패널 접기`)를 클릭하면, 채팅 패널과 상세 드로어가 함께 접힌다.** 다시 펼치면 채팅 패널과 (선택 매체가 유지된 경우) 드로어가 함께 복원된다.

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 기본(AI) | 최초 진입 | 인사말 + 추천 예시 + 입력창 |
| 추천 결과 | AI 추천 응답 | 패널 본문에 매체 리스트(채팅방 스크롤) |
| 매체 검색 | 검색 탭 선택 | 위치 입력 + 필터바 + 결과 목록 |
| 드로어 열림 | 매체 카드 클릭 | 좌측 패널 우측에 상세 드로어 |
| 패널 접힘 | 접기 핸들 클릭 | 채팅 패널 + 드로어 동시 접힘, 지도 영역 확장 |
| 결과 없음 / 로딩 / 에러 | ❓ | ❓ |
