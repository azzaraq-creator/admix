## 1. 목적
사용자가 서비스에 처음 진입했을 때 **AI에게 자연어로 요청해 옥외광고 매체를 추천받거나, 직접 매체를 검색**하도록 진입점을 제공한다. 두 가지 탐색 모드(AI 매체 추천 / 매체 검색) 중 하나를 골라 다음 화면으로 넘어가게 하는 출발 지점이다.

- 핵심 사용자: 옥외광고 매체를 찾는 광고주/마케터
- 성공 기준: ❓ (예: 프롬프트 입력 후 추천 화면 전환율 — 미정)

## 2. 권한
접근 권한은 **전체 사용자**(비회원 포함). 누구나 홈에 진입할 수 있다. 채팅(AI 매체 추천 발화) 사용량은 사용자 등급에 따라 **채팅 토큰(발화 횟수)**으로 제한한다.

| 사용자 구분 | 접근 | 제한 / 한도 | 한도 도달 시 동작 |
|---|---|---|---|
| 비회원 | 채팅 사용 가능 | **채팅 토큰 5회** | 소진 시 추가 발화 차단 → **로그인 유도** |
| 개인회원 | 채팅 사용 가능 | **30회** | 소진 시 추가 발화 차단 → 안내(상위 등급/기업 전환 등) |
| 기업회원 (사업자 미등록) | 채팅 사용 가능 | **100회** | 소진 시 추가 발화 차단 → **사업자 등록 유도** |
| 기업회원 (사업자 등록 완료) | 채팅 사용 가능 | **무제한** | 해당 없음 |

- `❓` **카운팅 규칙 미확정**: 무엇을 1회로 세는지(사용자 발화 1건 = 1회로 가정), 리셋 주기(누적/월/일), 비회원→회원 전환 시 잔여 횟수 처리 방식.
- 로그인 시 추가로 열리는 기능(내 제안서 등)은 각 메뉴 화면에서 다룸.

## 3. UI
화면을 위에서 아래(그리고 좌측 LNB → 중앙 콘텐츠) 순으로 블록 단위로 정리한다.

### 3.0 배경 영역
- **기능**: 화면 전체 배경 이미지로 분위기를 전달하고, 중앙 콘텐츠 가독성을 확보한다.
- **규칙**:
  - 전체 화면 배경 이미지 노출, 화면 크기에 맞춰 비율 유지.
  - 콘텐츠 영역 가독성을 위해 반투명 오버레이 적용.
  - 별도 인터랙션 없음(클릭/hover 동작 없음).
- `❓` 전달될 배경 이미지에 따라 오버레이 값(투명도)을 조정 — 기본값/조정 기준 미정.
- `❓` 배경 이미지는 고정인지, 교체·랜덤·시즌별 노출인지 미정.

### 3.1 LNB (좌측 네비게이션)
- **기능**: 서비스 주요 메뉴로 이동하는 좌측 내비게이션. 평소 **접힘(아이콘만)** 상태이며 펼치면 라벨이 보인다.
- **구성(메뉴 순서)**: 서비스 로고 → 고정 매체 → 이동·지역 매체 → 서비스 소개 → 내 제안서 → 문의하기 →(하단) 도움말 → 로그인/회원가입(또는 프로필).
  - `❓` 참고 PRD는 "회사&서비스 소개"로 표기, 펼침 디자인은 "서비스 소개"로 표기 — 정식 라벨 확정 필요.
- **규칙**:
  - **펼치기/접기**: 접힌 LNB의 **메뉴 아이콘 이외 영역(빈 공간) 클릭 시 펼침**, 펼침 상태에서 **상단 패널 아이콘 또는 빈 영역 클릭 시 접힘**. 로고·메뉴·도움말·로그인 등 인터랙티브 요소 클릭은 토글에서 제외(각자 동작 수행). 펼침/접힘은 width 애니메이션(300ms).
    - **반응형 (브레이크포인트 640px)**: **≥640px(데스크톱)** — 펼치면 LNB가 공간을 차지하여 **콘텐츠가 밀림(push)**. **<640px(모바일)** — 펼치면 **콘텐츠를 덮음(overlay) + 딤(반투명) 배경**, 배경 클릭 시 닫힘. 펼침 폭 224px.
    - `❓` 재방문 시 마지막 펼침 상태 기억 여부 미정.
  - **로고 클릭**: 홈 화면(`/`)으로 이동.
  - **메뉴 클릭**: 해당 메뉴 페이지로 이동(고정 매체 / 이동·지역 매체 / 서비스 소개 / 내 제안서 / 문의하기 / 도움말).
    - `❓` 각 메뉴의 라우트 경로 미정. `❓` 비회원이 "내 제안서" 클릭 시 동작(로그인 유도 vs 빈 상태) 미정.
  - **현재 페이지**: 해당 메뉴를 Active 상태로 표시.
  - **로그인/프로필 영역**(하단):
    - 비로그인: "로그인 / 회원가입" 버튼 노출 → 클릭 시 **로그인 모달** 노출.
      - 로그인 모달 구성: 이메일 입력 / 비밀번호 입력 / "로그인 유지" 체크박스 / "비밀번호 재설정" 링크 / 로그인 버튼 / 소셜 로그인(카카오·네이버) / 하단 "아직 회원이 아니신가요? **회원가입**" 링크.
      - "회원가입" 링크 클릭 → 회원가입(모달 플로우)로 진입.
      - `❓` 회원가입 모달의 단계·입력 항목, 로그인 실패/소셜 로그인 콜백 처리 규칙 미정(별도 화면 정책에서 다룰 수 있음).
    - 로그인: 프로필 노출 → 클릭 시 프로필 셀렉 드롭리스트 노출.
      - `❓` 프로필 드롭리스트 항목(마이페이지/로그아웃 등) 미정.
- **상태**: Default(기본) / Hover(마우스 오버) / Active(현재 위치).

### 3.2 서비스 모드 선택 토글
- **기능**: 중앙 콘텐츠의 탐색 방식을 전환하는 토글. "AI 매체 추천" / "매체 검색" 2개.
- **규칙**:
  - **기본값**: "AI 매체 추천" 활성화 상태로 진입.
  - **AI 매체 추천 선택 시**: AI 타이틀("AI를 통해 매체를 간편하게 추천받아 보세요!") 노출 + 프롬프트 입력 영역 표시.
  - **매체 검색 선택 시**: 타이틀 "어디에 광고하고 싶으세요?" 노출 + **단일 위치/주소 검색 필드** 표시(예시 안내 "강남역 역삼로 10길 6") + 검색 버튼(돋보기).
  - 토글 전환은 같은 홈 화면 내에서 중앙 영역만 교체(페이지 이동 아님).
- `❓` 토글 전환 시 입력 중이던 내용 유지/초기화 규칙 미정.

### 3.3 중앙 타이틀 + 프롬프트 입력 (AI 매체 추천 모드)
- **기능**: 자연어 프롬프트로 AI에게 매체 추천을 요청하는 입력 영역.
- **규칙**:
  - 타이틀: "AI를 통해 매체를 간편하게 추천받아 보세요!".
  - 입력창에 예시 안내 문구 노출(예: "강남에서 빌보드 광고 1억 예산으로 화장품 브랜딩 하고싶어요").
    - `❓` 이 문구가 placeholder(클릭 시 사라짐)인지 pre-fill(수정 가능 기본값)인지 미정.
  - "AI 생성" 버튼 클릭 → 입력 프롬프트로 추천 실행 후 **고정 매체 / AI 매체 추천 결과 화면**으로 이동.
    - **빈 입력/너무 짧은 입력 시**: "AI 생성" 버튼 **비활성**(유효 입력 전까지 클릭 불가).
    - 한도 소진(2번 참조) 상태에서 발화 시도 시: 차단 + 등급별 유도(로그인/사업자 등록 등).
    - `❓` "너무 짧음"의 기준(최소 글자 수), 필수 키워드(지역·예산 등) 유무 미정.
    - `❓` Enter 키 제출 지원 여부 미정.
- **예외 처리**:
  - 네트워크 오류: "일시적인 오류가 발생했습니다. 잠시 후 다시 시도해주세요."
  - AI 응답 실패: "추천 결과를 생성하지 못했습니다. 다시 시도해주세요."
  - `❓` 오류 노출 방식(토스트/인라인) 및 재시도 동작 미정.

### 3.4 위치 검색 (매체 검색 모드)
- **기능**: 광고하고 싶은 위치/주소를 입력해 해당 지역의 매체를 찾는 단일 검색 영역.
- **규칙**:
  - 타이틀: "어디에 광고하고 싶으세요?".
  - 단일 입력 필드 + 검색 버튼(돋보기). 예시 안내 문구 "강남역 역삼로 10길 6".
  - 검색 실행 → **고정 매체 / 매체 검색 결과 화면**으로 이동.
  - `❓` 예시 문구가 placeholder인지 pre-fill인지 미정.
  - `❓` 입력 형식(주소/지명/지하철역 등) 허용 범위, 자동완성·지도 연동 유무 미정.
  - `❓` 빈 입력 시 검색 버튼 동작(비활성/경고) 미정.

## 4. 화면 상태
화면 전체가 가질 수 있는 상태. (개별 블록 상태는 3번 안에서 다룸)

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 기본(default) | 서비스 최초 진입 | 배경 + LNB(접힘) + AI 매체 추천 모드 활성, 프롬프트 입력 영역 |
| 입력 중 | 프롬프트/위치 작성 중 | 유효 입력 시 "AI 생성"/검색 버튼 활성, 빈·짧은 입력 시 비활성 |
| 생성 중(로딩) | "AI 생성" 클릭 후 | `❓` 로딩 표현(버튼 스피너/화면 전환 후 로딩) 미정 |
| 한도 소진 | 등급별 채팅 토큰 소진(2번) | 발화 차단 + 등급별 유도(로그인/사업자 등록 등) |
| 에러 | 네트워크 오류 / AI 응답 실패 | 위 3.3 예외 처리 문구 노출 |

> 빈 상태/결과 없음은 홈 화면 자체에는 해당 없음(결과는 다음 화면에서 처리).
