## 1. 목적

관리자가 로그인 후 처음 만나는 화면으로, **방문자·회원·제안·문의 핵심 지표와 연간 추이, 최근 제안 리스트**를 한 화면에서 요약해 보여준다. 각 통계 카드에서 해당 관리 화면으로 바로 이동할 수 있는 진입점 역할을 한다.

- 핵심 사용자: 로그인한 관리자(마스터 포함)
- 성공 기준: ❓

## 2. 권한

접근 권한은 **로그인한 모든 관리자**. 대시보드는 로그인 기본 페이지라 메뉴 권한(`admin_permission`)과 무관하게 상시 노출·조회 가능하다. 상세는 [관리자 인증·권한 정책](admin-auth-permissions.md) §3 참조.

- **화면 접근 게이트**: `app/admin/(main)/layout.tsx`가 서버컴포넌트에서 쿠키 `admin_token` 존재를 확인 → 없으면 `/admin/login`으로 `redirect`. (토큰 유효성 검증이 아니라 존재 여부만 확인)
- **데이터 API 가드**: `GET /admin/dashboard`는 `get_current_admin`만 요구(권한 게이팅 없음). 즉 유효한 admin 토큰이면 누구나 조회. `require_permission` 미적용.
- **사이드바 노출**: "대시보드" 항목(`permKey: "dashboard"`)은 `AdminSidebar`에서 항상 노출(`permKey === "dashboard"` → `return true`).

> 통계 카드의 "회원/제안/문의 관리" 이동 버튼은 대시보드 자체 권한과 별개다. 이동 대상 화면(`/admin/members` 등)은 각자 `member`·`business` 권한으로 게이팅되므로, 권한 없는 관리자가 눌러 진입하면 해당 화면/API에서 막힌다(백엔드 403).

## 3. UI 블록 (위 → 아래)

화면은 좌측 **사이드바(공통 레이아웃)** 우측 본문에 렌더되며, 본문은 위에서 아래로 **① 페이지 타이틀 → ② 통계 카드 4종 → ③ 연간 차트 2종 → ④ 최근 제안 리스트** 순으로 세로 배치된다.

### 3.0 페이지 타이틀
- **기능**: 화면 제목 "대시보드" 표시.
- **규칙**: 정적 텍스트. 별도 동작 없음.

### 3.1 통계 카드 4종
- **기능**: 방문자·회원·제안·문의 핵심 지표를 카드로 요약. 3개 카드는 하단에 해당 관리 화면 이동 버튼을 가진다.
- **규칙**:
  - 데이터 출처: `GET /admin/dashboard` 단일 응답(`useDashboard`, staleTime 30초). 값이 아직 없으면 `?? 0`으로 폴백(로딩 시 0 표시).
  - 숫자 포맷: `toLocaleString()`으로 천단위 콤마. 방문자·회원은 접미사 **"명"**, 제안·문의는 **"건"**.
  - 카드별 내용:
    - **방문자 수**: 오늘 / 누적. (이동 버튼 없음)
    - **전체 회원 수**: 오늘 가입자 / 누적 가입자. 하단 버튼 **"회원 관리"** → `/admin/members`.
    - **전체 제안 건수**: 오늘 / 누적. 하단 버튼 **"제안 관리"** → `/admin/proposals`.
    - **전체 문의 건수**: 오늘 / 주간 / 월간 / 누적 (2열 배치). 하단 버튼 **"문의 관리"** → `/admin/inquiries`.
  - **집계 기준(백엔드)**: 날짜 경계는 **KST(UTC+9)**. "오늘" = 오늘 0시 이후, "주간" = 이번 주 월요일 0시 이후(`now.weekday()` 기준), "월간" = 이달 1일 0시 이후. 회원=`User`, 제안=`Proposal`, 문의=`Inquiry`의 `created_at` 카운트.
  - **방문자 수 특이사항**: DB가 아니라 **GA4 Data API의 홈(`pagePath == "/"`) `screenPageViews`(홈 진입 수)**. "오늘"=오늘 날짜 조회수, "누적"=해당 연도 누적(신규 속성이라 사실상 전체와 동일). GA4 미설정/실패 시 0. → §5 참조.
- `❓` 방문자 카드에 "이동 버튼"이 없는 것이 확정 사양인지(방문자 상세 화면 부재).

### 3.2 연간 제안 건수 차트 (막대)
- **기능**: 올해 월별(1~12월) 제안 건수를 막대 차트로 표시. 우상단에 연도 선택 버튼.
- **규칙**:
  - 데이터: 대시보드 응답 `proposalMonthly`(길이 12 배열). 없으면 빈 배열 → 각 월 0.
  - Y축 눈금: 5분할. 최댓값을 5의 배수로 올림, 최소 5 보장(`max(5, ceil(maxVal/5)*5)`).
  - **호버 툴팁**: 각 월 컬럼 전체가 투명 히트영역이라 값이 0인 달도 호버 가능. 호버 시 해당 월 값을 콤마 포맷으로 말풍선 표시. 말풍선은 기본 막대 위쪽, **위 공간(30px)이 부족하면 막대 아래로 뒤집어** 잘림 방지.
  - 하단 범례: "제안 건수".
- `❓` 연도 선택 버튼 동작(§3.4 참조) — 현재 막대 데이터는 서버가 올해 기준으로만 내려줌.

### 3.3 연간 방문자 수 차트 (라인)
- **기능**: 올해 월별 방문자 수(홈 진입 수)를 꺾은선 차트로 표시. 우상단에 연도 선택 버튼.
- **규칙**:
  - 데이터: 대시보드 응답 `visitorMonthly`(길이 12 배열, GA4 월별 홈 진입 수). 없으면 각 월 0.
  - Y축 눈금: 제안 차트와 동일 규칙(5분할, 5의 배수 올림, 최소 5). 눈금 라벨은 콤마 포맷.
  - 각 월 지점에 원 마커. 호버 중인 지점 마커는 반경이 커진다(4→5).
  - **호버 툴팁**: 제안 차트와 동일(월 컬럼 투명 히트영역, 값 콤마, 위 공간 부족 시 아래로 뒤집음).
  - 하단 범례: 선 + 원 마커 + "방문자 수".
- `❓` GA4 리포트 지연(코어 리포트 수 시간~48h)으로 최근 일자 수치가 과소 표시될 수 있음 — 화면상 안내/주석 노출 여부.

### 3.4 연도 선택 버튼 (YearSelect)
- **기능**: 두 차트 우상단에 있는 연도 선택 버튼.
- **규칙**: 현재 **"2026" 하드코딩 + chevron 아이콘**만 렌더. onClick·드롭다운·연도 변경 로직 **미구현**(정적 버튼). 서버도 항상 올해(`year.year`) 기준 데이터만 반환.
- `❓` 연도 변경으로 과거 연도 조회를 지원할지, 지원 시 API 파라미터(현재 `/admin/dashboard`는 연도 인자 없음).

### 3.5 최근 제안 리스트
- **기능**: 최근 제안을 표(CommonTable)로 표시. 우상단 "더보기" 버튼으로 제안 관리로 이동.
- **규칙**:
  - 데이터: `GET /admin/proposals`(`useAdminProposals`, staleTime 30초)의 `items`에서 **앞 10건** slice. 대시보드 응답이 아니라 제안 목록 API 재사용.
  - 컬럼: No · 제안명 · 회원명 · 매체 수 · 예상 예산 · 상태 · 접수일. (No는 1부터 순번 재부여)
  - 표 설정: 검색 비활성(`useSearch={false}`), `pageSize={10}`. (10건만 넘기므로 사실상 1페이지)
  - **"더보기" 버튼** → `/admin/proposals`.
- `❓` "최근" 정렬 기준(제안 목록 API의 기본 정렬이 최신순인지) — 프론트는 정렬 없이 앞 10건만 자름.

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 미인증 | 쿠키 `admin_token` 없음 | 레이아웃에서 `/admin/login` 리다이렉트(화면 진입 자체 차단) |
| 로딩 | 대시보드/제안 쿼리 응답 전 | 통계·차트 값 0, 리스트 빈 표(`?? 0` / `?? []` 폴백). 별도 스켈레톤 ❓ |
| 성공 | 데이터 수신 | 카드·차트·리스트 정상 렌더 |
| 방문자 0 (GA4 미설정/실패) | `ga4_property_id` 미설정 또는 API 예외 | 방문자 카드·라인차트 전 구간 0 (에러 노출 없이 graceful) |
| 결과 없음(제안) | 제안 0건 | 최근 제안 표가 빈 상태 ❓(빈 표 문구 미확인) |
| 에러(대시보드 API 실패) | `GET /admin/dashboard` 실패 | ❓(에러 UI 미확인, 현재 코드상 폴백 0 유지) |

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 · 비고 |
|---|---|---|
| 회원/제안/문의 카운트, 월별 제안 | `GET /admin/dashboard` (Postgres 집계) | 진입 시 조회, staleTime 30초. KST 날짜 경계 |
| 방문자 수(오늘/누적/월별) | GA4 Data API `screenPageViews`, `pagePath=="/"` | `dashboard_service`가 `ga4_service.get_home_visits(year)` 호출. **코어 리포트 지연 수 시간~48h** |
| GA4 설정값 | `GA4_PROPERTY_ID`(숫자 속성 ID) + 서비스계정(`GA4_CREDENTIALS_PATH` 또는 ADC/`GOOGLE_APPLICATION_CREDENTIALS`) | 둘 중 하나라도 비면 집계 비활성 → 0 반환 |
| 최근 제안 리스트 | `GET /admin/proposals` (`business` 권한 API) | 진입 시 조회, 앞 10건 사용 |
