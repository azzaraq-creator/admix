## 한눈에 보기

| | 전 😕 | 후 😊 |
|---|---|---|
| **새 매체** | 어드민·엑셀로 추가한 매체는 추천에 **안 나옴** | 저장하는 순간 **자동 반영** |
| **AI 태그** | 옛 엑셀 값만 사용 | 주소·카테고리·인구로 **자동 계산** + 엑셀 값 유지 |
| **타깃** | 근거 없음 | 인구(**최다 연령 1개 + 55%↑ 성별**) + 장소 규칙 + 직접 선택 |
| **검색 규칙** | 조건 **전부** 만족해야 함 → 태그 하나 비면 탈락 | 지역·예산·카테고리만 필수, 나머지는 **맞을수록 위로** |
| **사전에 없는 말** | 엉뚱한 코드로 바꾸거나 지어내서 **0건** | 매체명·노선·설명에서 **글자로 검색** |
| **추천 개수** | "2개 추천" → 카드 7개+ | 카드도 답변도 **딱 2개** |
| **추천 순서** | 답변한 매체가 카드 **중간에 숨음** | 카드 **1번부터 순서대로** 답변 |

## 새 검색 규칙

```
① 반드시 맞아야 함      ② 점수                     ③ 정렬
   지역                    검색어 낱말마다 +3          점수 높은 순
   예산                    업종·제품·목적·타깃 +1      → 연령·유동인구
   카테고리(말했을 때)                                 → 광고비
```

- **검색어** = 매체 자체의 형태·장소(트럭·래핑·엘리베이터 TV …)
  - 글자가 맞는 매체가 있으면 **그 매체만** 보여 줌 (없으면 무시 → 0건 방지)
  - 일반 낱말(광고·홍보·근처)은 제외, 표기 차이(랩핑↔래핑)도 찾음
- **광고할 내용**(팝업스토어 오픈 등)은 검색어가 아니라 제품·목적으로 처리
- AI가 **지어낸 코드**(예: "LOC-기차역")는 버림
- "**N개**"라고 하면 위에서 N개만
