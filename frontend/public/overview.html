OOH 광고 매체 추천 시스템

광고주의 자연어 발화에서 핵심 조건을 추출하고, 단계별 검증과 정렬을 거쳐 적합한 옥외광고 매체를 추천합니다.

1.

1

슬롯 추출 + 필수요소 검사

발화에서 6축 슬롯을 추출하고, 가중점수를 합산해 통과 여부를 결정합니다.

슬롯 점수 분류
지역2중요 필터 (DB 검색에 직접 작용)
예산2중요 필터
매체 타입2중요 필터
타겟1가벼운 주제 (정렬·설명 보조)
상품1가벼운 주제
목적1가벼운 주제
≥ 3 점 → 다음 단계 < 3 점 → 부족 슬롯 1개를 자연어로 질문
2

조건 충돌 검사

3 개 페어로 SQL 매칭 카운트를 확인합니다. 매칭이 0건이면 충돌로 판정하고, 사실 기반으로 안내합니다.

지역 × 예산
예산 × 매체 타입
지역 × 매체 타입
예시 — "성수에서 빌보드 광고 백만원으로 하고싶어"
성수 빌보드는 최소 1,500만원이라서 현재 조건으로는 추천이 어렵습니다. 예산을 조정하시거나 다른 지역으로 변경이 필요합니다. 가장 저렴한 곳은 강남구 (최소 5백만원~) / 성동구 (최소 1,500만원~)부터입니다.
3

1차 추천 리스트

  • • 조건 통과 시 가격순 Top-20 매체를 표시합니다.
  • • 모든 매체에 위·경도(lat/lng) 값을 보유 → 지도 시각화 예정.
  • • 타겟·상품이 비어 있으면 부드러운 추가 질문을 한 번 던집니다.
  • • 사용자가 답변하면 → 상세 추천 단계로 진입.
2.

상세 추천 — 시도한 방법론과 한계

타겟·상품 답변이 들어오면 정밀 정렬을 시도합니다. 3 가지 방법을 시도했고 각각의 한계를 확인했습니다. 현재는 C 방법을 기본으로 사용합니다.

# 방법 데이터 상태
A 매체 설명 텍스트 description 임베딩 / 키워드 count 변별력 부족
B 매체 인구통계 (엑셀) 매체별 연령/성별 % (House of OOH) 신뢰도 낮음
C 서울시 상권 인구분포 상권 1,650 + 분기별 유동인구 ✓ 현재 default
A

매체 설명 텍스트 활용

방식

광고 매체의 description 을 임베딩한 뒤, 사용자 발화와의 cosine 유사도로 정렬. 또는 키워드 count 방식으로 매칭 횟수 비교.

한계 — 변별력 부족

위치가 유사한 매체는 description 도 비슷해서 점수가 거의 동일하게 나옵니다. 예: 강남 빌딩 외벽 전광판 30개가 모두 비슷한 cosine 점수.

B

매체 자체 인구통계 (엑셀)

방식

House of OOH 가 제공한 엑셀의 매체별 연령/성별 % 데이터에, LLM 이 사용자 타겟에서 추론한 가중치를 곱해 점수화.

한계 — grouping 단위가 비교적 큼

엑셀의 "조사 지역" 단위로 demo 값이 부여됩니다 (구 단위는 아님). 같은 조사 지역 매체끼리는 같은 demo 값을 공유하므로, 한 발화 안에서 매체가 갈라지는 정도가 크지 않습니다.

예시 — 한 발화당 2~3 개 조사 지역으로 묶임
  • • "성수" → 성수역 / 성수카페거리
  • • "강남" → 강남역 / 강남관광특구
C

서울시 상권 영역 + 인구분포

현재 default
방식
  1. 서울시 상권분석서비스의 1,650 상권 (영역 폴리곤 + 분기별 인구분포 데이터) 저장
  2. 매체의 lat/lng → 가장 가까운 상권에 매핑 (≤ 3 km)
  3. 상권 인구분포 × LLM 추론 타겟 가중치 → 매체별 점수 산출
장점 — B 보다 세밀한 grouping

구 단위 25 개 대비 1,650 상권으로 더 세밀. 예: "성수" → 성수동카페거리 / 성수역 / 경수초등학교 / 뚝도시장 등 여러 상권으로 분산.

한계 — 같은 상권 매체는 동일 점수

한 상권 안에 매체가 여러 개 묶인 경우 (예: 국기원 상권 12 매체) 모두 같은 상권 점수를 받습니다. B 와 본질이 같은 grouping 문제이지만, 단위(상권)가 더 세밀해 발화에 따라 더 잘 분산되는 편.

3.

향후 개선 / 보완 필요 사항

Media Type

매체 타입 정확한 구분

빌보드 등 매체 타입을 더 명확히 분류해 사용자가 필터할 수 있도록 구분 보강 필요. 현재 카탈로그는 텍스트 매칭 기반이라 동의어/세부 분류가 섞여 있음.

Price Coverage

금액 데이터 보충

전체 922 매체 중 121 매체 (≈13%)에 가격 정보가 없어, 사용자가 예산을 지정하면 그만큼 후보에서 자동 제외됩니다. 가격 데이터 보충이 필요.

Cost Efficiency

가성비 (금액 ÷ 송출횟수)

금액 대비 송출횟수(노출량)로 가성비 추천이 가능할 것으로 보임. 현재 데이터에는 송출횟수 정보가 없어 송출횟수·금액 데이터 모두 보충 필요.
